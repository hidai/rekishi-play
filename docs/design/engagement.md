## §2 要因A — 入口に「その人を知りたくなる理由」がない【深掘り済み 2026-07-29】

作品が最初に結ぶ契約が「**この人の一生を生きられる**」ではなく「**歴史の謎に答えを出す**」になっている。掘った結果、症状はもっと具体的だった。

**A-1 7作すべての「謎」が同じ一つの型で、しかも大人の問いだった。**
7作中7作が「なぜ、〜だったのに〜だろう？」＝**評判の逆説型**。うち5作は「**後世どう語られたか**」を問うている（悪役として語られた／神にまつり上げられた／天才の話はだれが作った／その声はだれの筆で残ったか／なぜ名が残らなかったか）。これは**史学の問い**であり、〈知らない人物〉×〈その人物の語られ方〉＝**二重の抽象**。10歳が入口で受け取るには遠い。

**A-2 強いフックは全作にある。ただし全部"降格"されている。**（＝材料不足ではなく配置の問題）
家康「六さいで人質に出される（三さいのとき母は家を出された）」／ダビンチ「私生児で、学校に入れない」／政子「見張り役の家の娘が、見張られている当人を選ぶ」／栄一「十七で『百姓のくせに』と笑われる」「外国人を焼く計画」／海舟「父はけんかと道楽ばかり」。**どれも知識ゼロで刺さる具体**なのに、入口の主役は謎で、これらは顔タップのトーストか章一の本文に置かれている。

**A-3 「はじめる」を押すと、物語でなく"目次"が出る。**
タイトル →（はじめる）→ **年代記＝7章の一覧、6章はロック**。起動から最初の1文までにメタ画面3枚。**最初の「選ぶ」までに 6〜7画面・287〜779字**（章一の実測）。しかもその選択は結果が変わらない（要因B）。

**A-4 章一の書き出しが 6/7 で「自己紹介」。**
「きみの名は◯◯。〜の子だ」＝人物カードの読み上げ。唯一の例外が最新の渋沢（いきなり事件から入る）。**ループは書き出しでは正解に近づいていたが、入口画面までは波及していない。**

### 案の評価（掘って残ったもの・落としたもの）

| 案 | 判定 | 理由 |
|---|---|---|
| **フックの昇格**（既存の具体を入口の主役に） | ✅ 残す | 材料は全作にある。データ移設に近く最も安い |
| **謎の型を変える**（評判の逆説→行為の並置「同じ人だ。なぜ？」） | ✅ 残す | hidenaga で一度成功済み（教科書→信長・秀吉） |
| **目次を後ろへ**（はじめる→いきなり章一。年代記は再訪用） | ✅ 残す | **実装可能を確認**: `startChapter` は再開位置も扱うので `TitleScreen` の遷移先を差し替えるだけ。年代記はトップバーのパンくずから残る。作品データ不変 |
| **事件一覧**（人物一覧をやめる） | △ 保留 | `WorkCard` に1行足せば可能。ただし「知らない顔7つ」問題は残る |
| **既知に接ぐ**（一万円札・モナ・リザ） | △ 部分解 | 使えるのは 4/7。全作の解にならない |
| **予告編を流す** | ⛔ **いま作れない** | 現在の絵では「正面顔のスライドショー」にしかならない＝**D の後でなければ成立しない**（A と D の依存を実証） |
| **作品を絞る/隠す** | 保留 | どれを隠すかの根拠が無い（観察が要る） |

## §3 要因B — 選択に意味がない【深掘り済み 2026-07-29】

**B-1 エンジンは最初から分岐できる。使っていないのは書き手だけ。**
`Choice.to` は選択肢ごとに別のシーンを指せる。選択履歴はセーブに載り（`recordChoice`）、**「分かれ道図鑑」は「まだ見ていない枝」を数える機能まで持っている**（`branches.ts`）。カード到達解析も `choices[].to` を辿るグラフ探索で書かれている。**つまり分岐を前提に設計された器に、直線の物語だけが入っている。**

**B-2 分岐用の本文も、すでに書かれている。**
「もしも」パネル（`hist.moshimo`）は 1作あたり 5〜9本、**本文は中央値 98〜187字**＝シーン本文の予算（300字）にそのまま収まる大きさ。いまはそれが**選択直後のモーダル**に閉じ込められ、読み終わると同じ画面へ戻る。
しかも VISION 原則1 は「非史実の選択には**『もしも』の反実仮想を見せてから史実に合流させる**」と書いている。**憲法はもともと分岐を求めていて、実装がそれをポップアップに圧縮した**——「外した方がむしろ面白い」はモーダル1枚では成立しない。

**B-3 ただし、いま分岐シーンを足す余地が無い作品が3つある。**
章の本文予算は 1000字。実測の余白は **kiyomori 5字・ieyasu 2字・shibusawa 5字**（最小の章）。つまり **1文も足せない**。予算を緩めるのは⛔（人間のみ）。
→ **解は「足す」ではなく「置き換える」**: §4 が示すとおり主線には説明が積もっているので、**説明を削って、空いた予算を分岐に使う**。これなら予算に触らず、B と C を同時に解ける（**自律で可**）。

### 案の評価

| 案 | 判定 | 理由 |
|---|---|---|
| **「もしも」をシーンに昇格**（1〜2画面で合流） | ✅ 本命 | 器も本文も既にある。憲法が元々求めていた形 |
| **説明を削って分岐の予算を作る** | ✅ 同時に必要 | B-3 の制約はこれでしか解けない（予算緩和は⛔） |
| **選択の記憶**（後の章で人物が覚えている） | ✅ 残す | セーブに履歴はある。参照する側が無いだけ |
| **メーターを働かせる** | △ | まず分岐。メーターは分岐が出来てから意味を持つ |
| **ままならない資源**（金・信用・時間） | △ 保留 | 新概念。分岐が効くか見てから |
| **予算を緩めて分岐を足す** | ⛔ | 体験予算の緩和＝ハード境界。提案のみ |

## §4 要因C — 画面が「教材」の顔をしている（解説が物語を上回る）

解説/物語比 0.9〜1.4、1画面 2〜3ブロック。メーターHUD・西暦・場所・本文・内語・赤枠・たしかさマーク・もっと深く・信条…と、物語以外の家具が常に画面にある。大人フィードバックの「赤枠が引きはがす」は症状で、**総量**が原因の可能性が高い。史料批判（この話の出どころは1つだけ、等）は作品の美点だが、**知らない人の物語の1画面目でそれを言う**と、投資する前に「これは本当じゃないかも」を渡すことになる。

**❌ まず自分の仮説を1つ落とした。「装置は本文の焼き直しでは？」→ 違う。**
赤枠・もっと深くの本文と、同じ画面＋直前の画面の本文との**6文字ぐみの重複率は全作で平均 0〜1%**。装置はちゃんと**新しい情報**を言っている。つまり C は「重複を消す」問題ではない。

**C-1 真の姿は〈量〉と〈語り手の切替〉。**
1章あたり **本文 ≒1000字 に対して 装置 500〜2000字**。装置の割合は全作で **47〜58%**。読者は1画面ごとに、なりきりの二人称（物語）→ 外からの「え！？」（赤枠）→ 確度の記号（史学）→ 事典（もっと深く）と、**語り手を3〜4回乗り換える**。大人フィードバックの「引きはがされる」はこの乗り換えのこと。

**C-2 ★体験予算は、いちばん教科書的な半分を数えていない。**
`style-budget` が数えるのは `Scene.text` だけ。**赤枠・もっと深く・信条・史実パネルは無予算**。実例:

| | 本文（予算1000） | 装置（予算なし） | 実際に読む字数 |
|---|---|---|---|
| kiyomori 章二 | 999 ＝ **合格** | 1810 | **2809** |
| shibusawa 終章 | 1020 | 2028 | **3048** |
| hidenaga 章三 | 571 | 509 | 1080 |

**教科書化を止めるために作った計器が、教科書そのものの部分を見ていない。**

**C-3 ★天井への張りつき（Goodhart）。**
章あたりの本文（ゲートの指標）の平均は **hidenaga 610字**に対し **kiyomori 918・ieyasu 950・shibusawa 920**。予算 1000 は「hidenaga の実測＋伸びしろ」として引かれたのに、**後発の作品はその伸びしろを使い切った**。全49章のうち13章が天井の 5% 以内にある。**機械は「合格」と言い続けながら、唯一『引き込まれる』と検証されたコーパスから 50% 離れていった。**

### 案の評価

| 案 | 判定 | 理由 |
|---|---|---|
| **説明を削る**（削った分は §3 の分岐へ） | ✅ 本命 | B の制約を解く唯一の道でもある。自律で可 |
| **装置にも予算を付ける**（章の総読字数を数える） | ✅ 計測の追加＝自律で可 | いま完全な盲点 |
| **層を割る**（知識は章末／手帳へ） | ✅ 残す | 大人フィードバックの提案そのもの |
| **史料批判を"事件"化**（毎画面やめ、作品に1〜2回） | ✅ 残す | 入口で「本当じゃないかも」を渡す問題（§2）も同時に解ける |
| **1画面の要素数に予算** | △ | 上2つが効けば自然に下がる。まず総量から |

## §5 要因D — 絵が感情を運ばない【深掘り済み 2026-07-29・実験あり】

**D-1 感情のチャネルが「背景のグラデーション5種」しかない。**
顔スペックは `brow`(5種) / `eye`(8種) / `mouth`(6種) を持つ＝**表情の語彙はすでにある**。しかし**スペックは人物ごとに固定**で、場面では変えられない。`@変種` 24個のうち感情の変種は3つだけ（`@grief` `@fear` `@fall`）で、残りは全部**年齢**（`@child` `@young` `@old` `@prime`）。つまり **顔は「誰か」を示す記号であって、「いまどう感じているか」を一度も担っていない**。エンジンの設計目標が識別（別人距離ゲート・`face-variety` テスト）だったことの帰結。
しかも **masako は closeup 17枚すべてが1人・正面、shibusawa は25枚**＝**新しい作品ほど、この最も弱い装置に依存している**。

**D-2 実験**（shibusawa 1-c「やめろ、犬死にだ」/「なら、斬れ」を4通りに描いて比較）

| 版 | 変えたもの | 結果 |
|---|---|---|
| V0 | 現状（正面・等倍・左右対称） | 証明写真が2枚。場面が読めない |
| V1 | **表情だけ**（怒り／必死） | **一目で読める。構図は現状のまま**。→ ✅ 最も安く、最も効いた |
| V2 | **構図だけ**（相手を手前に大きく・きみを奥に小さく） | 遠近が出て「対決」に近づく。→ ✅ engine 側だけで可能 |
| V3 | 表情＋構図＋場（行灯・柱・刀） | 読めるが、小道具がバストと衝突して隠れた |

**❌ 落とした案＝「向かい合わせにする（顔を反転して内向きに）」。** 実験で確認: **現行の顔は左右対称なので、反転しても絵が1ピクセルも変わらない**。斜め・横顔の頭部が要り、それは `face.ts`（848行）への本質的追加＝重い。**「closeup が対面に読めない」（4度目の検出）への正しい答えは、ミラーではなく〈表情＋遠近〉だった。**
**△ 場・小道具**は効くが、バスト位置との衝突を解く配置規則が要る（地図ラベル衝突ゲートと同種の問題）。
**動きは既に語彙がある**（CSS keyframes 19個・`prefers-reduced-motion` 対応済み）のに、**人物には一度も使われていない**（動いているのは雪と灯りだけ）。

**D-3 実験2＝表情の語彙は足りるか。** 同じ人物（`p-eiichi@young`）に既存の語彙だけで9通りの表情を当てて描いた。結果 **新しい絵を1本も描かずに8つの情感が読める**（怒り／恐れ／悲しみ〔`eye:'cry'` は涙まで描かれる〕／喜び／決意／おどろき／疑い・値ぶみ／耐える）。**D の本命に必要な絵の追加はゼロ**と確定。再現用の指定:

| 情感 | brow / eye / mouth | | 情感 | brow / eye / mouth |
|---|---|---|---|---|
| 怒り | angry / sharp / frown | | 決意 | stern / sharp / flat |
| 恐れ | worried / wide / frown | | おどろき | soft / wide / soft |
| 悲しみ | worried / cry / frown | | 疑い・値ぶみ | stern / narrow / flat |
| 喜び | soft / lively / laugh | | 耐える | calm / closed / flat |

**見つかった語彙の穴は1つだけ**: 開いた口の「叫び・怒号」が無い（`laugh`/`grin` は喜びの口）。**恐れ と おどろき** も近い（どちらも `wide`）。
**ついでの発見**: 栄一@young の固定スペックは元から「やや困り顔」なので、**青年期の全場面で困った顔をしている**。

### 案の評価

| 案 | 判定 | 理由 |
|---|---|---|
| **場面ごとの表情上書き**（closeup に `expr`） | ✅ 本命 | **語彙は既存で足りる（実験2で確定・新規の絵ゼロ）**。engine の1フィールドで全作 64枚に効く。人物ごとの `@変種` 手書きより安い |
| **遠近（近い人を大きく）** | ✅ 残す | engine 側だけ・データ不変 |
| **人物にも動きを** | ✅ 安い | keyframes の語彙も reduced-motion 対応も既にある |
| **場・小道具** | △ 条件つき | 配置規則が要る。先に表情・遠近をやってから |
| **顔を向かい合わせる（ミラー）** | ⛔ **落とした** | 顔が左右対称＝実験で無効を確認 |
| **斜め・横顔の頭部を作る** | 保留（重い） | face.ts の本質的拡張。表情・遠近で足りるか見てから |

## §6 要因E — 「なりきり」に動詞がない／収集が自動【深掘り済み 2026-07-29】

**E-1 動詞の在庫は実質2種類しかない。**
ミニゲームは **`sort` 型（つぎはどれ？＝正しい順に積む）1種類だけ**で、7作合わせて6か所。観察ビューは davinci の3か所のみ。**ieyasu と masako は、30画面を通して手を動かす場面がゼロ**。
しかも唯一の能動装置であるミニゲームには「**とばして 進む**」がある＝**遊ばなくても進める**。

**E-2 弱い相関だが記録しておく。** 唯一「引き込まれる」と検証されたコーパス hidenaga が、ミニゲーム最多（3か所）。装置ゼロの2作（ieyasu・masako）は、いずれも「熱が足りない」系の宿題が既に立っている（BACKLOG の ieyasu の熱／masako の 1-d）。

**E-3 収集は自動。** カードは `onEnter` で入場と同時に付与。到達不能カードを潰す過去の修理は「**全部そろうことの保証**」＝自動化をさらに強める方向だった。集める行為が存在しないので、集まっても報酬にならない。

### 案の評価

| 案 | 判定 | 理由 |
|---|---|---|
| **人物ごとに動詞を1つ決める**（栄一＝値をつける／政子＝人を配る／家康＝待つ） | ✅ 本命 | 主題と遊びが一致する。ただし新 kind の設計が要る |
| **既存装置の横展開**（sort・observe を全作へ） | ✅ 安い | engine にある。ただし sort 1種類では7作が同じ顔になる |
| **「とばして進む」を見直す** | △ | 遊ばせたいなら逃げ道は要検討。ただし詰ませない原則とのバランス |
| **カードの一部を探索・選択に紐づける** | ✅ 残す | §3 の分岐と同時にやると効く（枝ごとに違う札） |
| **信条を読者がつくる** | △ 保留 | 面白いが、creed は作品の背骨なので影響が広い |

## §7 要因F — ループ側（fix the loop）【深掘り済み 2026-07-29】

## §9 総合 — 要因はつながっていた（2026-07-29）

掘って分かった依存関係。**独立した6つの問題ではなく、1本の鎖**だった。

```
F(識別ゲートが表情を使っている) ──┐
                                  ├→ D(絵が感情を運ばない) ──→ A(入口・予告編が作れない)
C(説明が主線を埋めている) ────────┼→ B(分岐を足す予算が無い)
                                  └→ A(入口で史料批判が鳴る)
E(動詞がない) …独立（ただし最も重い）
```

- **D の前提工事は F にある。** 表情を場面ごとに動かすには、先に「表情を除いても別人と分かる」ことを保証する必要がある（実際に手当てが要るのは3枚）。これは**より厳しい要求＝自律で可**。

- **A の一部は D と C が解く。** 予告編は絵が変わらないと成立せず、「入口で本当じゃないかもと言う」問題は C の史料批判の置き場で解ける。
- 残る A 固有（目次を後ろへ／フックの昇格／謎を行為の並置へ）は**engine と作品文言の入れ替えだけ**で、依存が無い＝いつでも着手できる。

> ⚠️ **下の着手順は §10 で訂正した。** 工学的な安さ（依存関係）で並べたもので、**証拠の強さでは並べていない**。残してあるのは「実装の依存関係」としては正しいから。優先順位は §10 を見ること。

### 実装の依存関係（優先順位ではない）

1. **F 前提工事**: 識別を表情以外で担保（3枚に特徴を1つ足す）。
2. **D**: 場面ごとの表情＋遠近。**engine のみ・作品データ不変**で 64枚すべてに効く。
3. **C→B を1章で同時に**: 説明を削り、空いた予算で「もしも」をシーンに昇格させる。
4. **A**: 目次を後ろへ・フックを入口の主役に・謎を行為の並置へ。
5. **E**: 人物ごとの動詞（新 kind）。最も重いので最後。

## §10 結論（2026-07-29・調査ここまで）

### 10-1 自分の推論を壊しにいった結果

**1. いちばん確からしい原因は〈用量〉である。** 1画面あたりに読ませる量・覚えさせる人の数・何もせずに読み続ける長さ。これは**実際の観察が2回、同じ方向を指した唯一の軸**であり、7作の中で実測の差が最大の軸でもある。

**2. 構造（分岐ゼロ・無表情・目次が先・史学の謎）は〈天井〉であって〈差〉ではない。** 全作に共通なので「なぜこの作品はダメでこの作品は良かったか」は説明しない。ただし**「どれもそこまで深くは引き込まれない」「大人が遊ぶと無風に見える」を説明する**のはこちら側で、上限を上げたいなら結局ここを触ることになる。**優先度は下げるが、捨てない。**

**5. 人物追加の凍結は妥当。** 追加は用量問題を直接には悪化させないが、**7人並ぶ入口**（要因A）を強め、検証されていない構造を複製する。凍結したまま、既存作で確かめるのが正しい。

対照群のつもりだった**第二章**を人間が遊び、**5件が「意味が分からない」**で止まった——「外国人を焼くのが、なぜ幕府の的なのか」「**攘夷**という言葉の意味が分からない」「慶喜は徳川なのか（将軍とは書いてあるが徳川と結びつかない）」「慶喜の『聞いておく』は**何を**聞くのか」「『きみの座』の図が勢力図に見えて意味が取れない」。人間の結論＝**「第一章との比較以前の問題では？」**

**★これは正しい。** 対照群が「同じ作りで、ただ重い章」ならば落差は用量を測る。だが**第二章は筋が通っていなかった**＝落差は「用量」と「壊れている」を分離できない。**比較実験は私の設計ミスで、取り下げる。**

**★5件のうち2件は、私の第一章の削りが作った。** ①「幕府が港をひらいた」＝外国人を襲うことが幕府への反逆になる、という因果と、②「攘夷」の意味は、**どちらも初稿で消した 1-b の「もっと深く」にあった**。第一章から抜いたことで、第二章がその上に立てなくなった。**章をまたいで効いている説明を、章の中だけ見て削った。**

**★残り3件は元からの欠陥**（一橋と徳川が結びつかない／「聞いておく」に目的語が無い／図の文法違い）。つまり **7作は「筋が追えるか」を一度も検査されずに出荷されている。**

### 直したもの

| 指摘 | 直し方（言葉を増やさない） |
|---|---|
| 幕府の的になる理由 | 1-b「**幕府が**港をひらき」＋1-d「外国人をおそう＝招き入れた幕府に**弓を引く**のと同じ」 |
| 攘夷が分からない | **本文から「攘夷」を消した**（制度語は本文に出さず card / deep へ＝design §0-5）。地の文は「外国を 追いはらえ」 |
| 慶喜は徳川か | 「一橋家は、**将軍を出す徳川の一族**だ」＝1文の言い換え |
| 「聞いておく」の目的語 | 直前に「**次にやりたいことを一つずつ申し上げた**」を置いた |
| 「きみの座」の図 | **外した**。`assembly`（席の図）は"部屋の座と陣営"の文法なので、**一人の立場の移り変わり**を入れると勢力図に読める＝**仕組みの流用**。むすびは対面の絵（表情つき）に差し替え |

⚠️ **同じ疑いが `seatDown`（章四）と `seatAll`（終章）にも残る**（`seat` は未使用になった）。「変わっていく立場」を描く絵は engine に無い＝**藍の絵と同じ空白**。まとめて判断する。

### ★ループ側の結論（ここが本体）

**ふりがなの帳簿は「読めるか」しか見ていない。「読めても意味が分からない語」は、どのゲートも見ていない。** 人間が最初に言った「**すでにその人物のことを知っている読者を前提にしている**」は、じつはこの層の話だった——ループはそれを「『有名な』等のマーカー語」と解釈し、9サイクルかけて 63→3 にした。**マーカーは消えたが、前提は消えていない。**

**機械化を試して、失敗した。** `scripts/glossary-audit.ts` を書いて実測したが、**ルビが付くのは「漢字が難しい」語であって「概念が難しい」語ではない**ため、出力73語は地名（飛鳥山・兜町）と日常語（椅子・値段）に埋もれ、実際に止まった語（攘夷・一橋）は上位に出ない。**この層は機械では捕れない**——スクリプトは候補リストとして残し、ゲートには**しない**。

**＝検出器は読者役しかない。** `/eval-work` に「**各画面で『いま何が起きた？』を一文で答えさせ、答えられない画面を報告させる**」を足すのが、7作すべてに対する唯一の実効的な検査。**これが最優先**（人間が手作業でやっていることの機械化）。

### 次にやること（順に）

3. 用量の検証は**そのあと**。対照群として使える章が無い以上、**まず全部の筋を通すのが先**。

## §16 型3 — 制度語（読めるのに意味が届かない語）2026-08-01

**規律**: docs/WRITING.md 書法13「**制度語は、その場で一句で言い換える。言い換えられないなら
主線から降ろす。同じものを2つの語で呼ばない**」。成功例はコーパスの中にあった（「宋（今の中国）」
「蘭学、オランダ語で 学ぶ 西洋の 学問」）ので、規律はその実例の一般化として書けた。

**計器**: `scripts/lib/institution-audit.ts`＋`tests/institution-gloss.test.ts`（作品×章のラチェット）。
初版の実測は **7作で 71件**（hidenaga 13・ieyasu 15・katsu 12・kiyomori 10・masako 10・shibusawa 7・davinci 4）。

**★§12 で「機械化は失敗」と書いたのは、半分だけ正しかった**。失敗したのは
`scripts/glossary-audit.ts`＝**ルビを候補の入口にした**設計で、ルビは「漢字が難しい」の印であって
「概念が難しい」の印ではないため、出力が地名と日常語に埋もれた。**語を手で選べば機械は使える**
——PREMISE_MARKERS と同じ「人が育てるリスト」に戻すと、73語の泥から 71件の名指しへ変わる。
*機械にできないのは「どの語が難しいか」の判定であって、「その語がその画面で裸か」の走査ではない。*

**この計器が引いた線**（判定は3つだけ）:
- **初出主義**＋**面ぐるみ**——同じ画面のどこかで言い換えていればよい（place が語を出し本文が受ける形）。
- **後の面（deep・カード）の説明は数えない**。読者はそれを開かない＝型3 の中身そのもの。
- **言い換えを別の制度語で書いたら、それも初出**（「幕府（将軍の政府）」は 将軍 が裸のまま）。
  ゲートを書いていて初めて見えた形で、注入テストに残した。

**hidenaga（1作目の棚卸し・入口＋章一）**: 天下＝入口で「天下（日本 ぜんぶ）」と一句そえた
（作品の背骨の語なので、読者が最初に会う面で払う＝以後の章は裸で使える）／spark の「天下人 兄弟」は
「のちに 天下を とる 兄弟」へ＝**語を増やさず既出の語で言い直す**／**武士→侍・農民→百姓に統一**

### 19-1b ★`class="speak"` は「他人の声」ではなかった（自己レビューが実データで摘出）

型9 の時と同じく、**この回も欠陥を出したのは code-reviewer サブエージェント**（eval の軸は全部通っていた）。3件:

- **きみ自身の台詞も同じ枠で書かれている**——渋沢 6-b「きみは 静岡へ 行き、その 前に すわった」→

  「そう 聞かれた」）。⚠️ 錨を目的格（きみを・きみに）へ絞る手も試したが、**実データの半分**（「母うえ。」等の
  正しい呼びかけ）を落とした＝**主語省略のある言語では、格で話者は決まらない**。採った形は
  ①**名で呼ぶ声・二人称の声は、きみ自身の声ではありえない**ので無条件に数える
