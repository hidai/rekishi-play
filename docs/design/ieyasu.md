## 0. 設計制約（この企画が守るべき枠）

リサーチ・VISION・WRITING から、企画・執筆が最後まで守る制約を先に固定する。

1. **確度マークの尊重＝本作でも"作品の中心装置"（G6/G7・katsu から継承）**: リサーチ §0 の確度（◎ほぼ確実／○概ね確実／△諸説・議論中／☆伝説・俗説・**神格化史料のみが出所**）を尊重する。katsu が「本人談のみ＝☆」を前面装置化したのと同型に、**家康では「神格化史料（東照宮御実紀・神君言行録の類）のみが出所＝☆」を前面化する**。△・☆を断定文で書かない。**これが本作の脱英雄化のエンジンそのもの**（§0-3・§1）。
2. **創作と史実の区別（G7）**: 台詞・内心・場面の創作は「——気がした」等で史実断定を避ける。同時代に記録の無い場面（三方ヶ原の内心・死の床・神号論争の細部）は既存の `Hist.seal:'心'` 系文法で「これは記録にない、きみが埋める」と枠づける（hidenaga/kiyomori/katsu 7-a2 の文法）。
3. **本作固有の"史料批判の向き"＝「勝者が積んだ神君像を剥がす」**（リサーチ §3・§8）:
   - hidenaga＝無名の裏方を過小評価から救う（上げる向き）／kiyomori＝世間の"悪役"ラベルを剥がす（是正の向き）／katsu＝**本人が語った**英雄譚を疑う（本人談を疑う向き）。
   - **家康＝死後250年かけて勝者（幕府）が積み上げた神君像を、一枚ずつ疑う向き**。剥がす対象が「世間」でも「本人談」でもなく**勝者の公式史書と各地東照宮の言行録**にある。しかみ像の「戒めのため」通説（§3-3）・東照公遺訓の偽作説（§3-4）・神君伊賀越えの忍者活躍譚（§3-11）・脱糞逸話（§3-2）——**神格化・美談化された逸話のほぼ全てに近年の反証／論争がある**（リサーチ §6・§8 で確認済み）。katsu で確立した史料批判の筋力がそのまま転用できる。
4. **英雄化と悪役化の"二重の罠"（リサーチ §6 リスク(c)・§8＝本作固有の最重要バランス）**:
   - **英雄化を避ける**: 家康は3人の中で最も英雄像（天下人・律儀者・神君）が強固。§0-3 の史料批判がブレーキを兼ねる。
   - **悪役化を避ける（逆張りの罠）**: 「律儀者神話を剥がす」ことに寄りすぎ、家康を単なる冷酷な策士に描き直すのは別の単純化。方広寺（§3-9）・築山殿信康事件（§4-6）のような割り切れない事実は**断定的な「非情な家康」像にせず、諸説・不明点を残したまま提示**する。確度マークは「悪人判定器」でなく「歴史の天気予報＝わからないことは調べる余地・宝」（VISION 原則6）。この register の較正が**パイロットシーンの主目的**（§9）。
5. **シニカルの罠のケア（katsu §0-4 の教訓を継承）**: 史料批判を効かせるあまり子どもが冷笑的になっては大目標2を毀損する。着地は「神君像は盛られている。でも、戦国の乱世を終わらせ260年の泰平を開いた事実は消えない。**盛りを割り引いてもなお残るもの**を、なりきって確かめる」。katsu の「語りを疑ってもなお残る芯」の家康版。
6. **ハード境界（AI は自律で越えない）**: セーブは**新規 saveKey（`ieyasu_save_v1`）**を新設＝既存 `hidenaga_save_v1`/`kiyomori_save_v1`/`katsu_save_v1` スキーマに触れない。VISION/CRITERIA 本文改訂も体験予算の緩和も本企画では発生しない。→ **本企画（および GO 後の骨組み）はハード境界に抵触しない**。

## 1. 貫通する謎（riddle）と、その解き方

### 1-1. 謎の核（リサーチ §6 の A案・B案を接続した推奨案）

> **「律儀者と 言われた 家康が、いちばん 長く 仕えた 主家（豊臣）を、なぜ 自分の 手で ほろぼしたのか？ ——そして なぜ その 家康は、死んだ あとに『神（東照大権現）』として まつり上げられたのか。その『神君』の すがたは、どこまで ほんとうなのか。」**

- **なぜこの謎か**: リサーチ §6 は貫通の謎に A案（なぜ律儀者が主家を滅ぼしたか＝**割り切れなさ**・大目標2）と B案（なぜ死後に神に祭り上げられたか＝**勝者の歴史をどう疑うか**・史料批判）を挙げ、「**A案とB案は排他的でなく両立可能**（『主家を滅ぼした男が、なぜ死後に神格化されたのか』で一本にまとめられる）」と明記した。本提案はこの接続案を採る。
  - **A（表の謎）＝人間理解の縦糸**: 今川→信長→秀吉と主君・同盟者を渡り歩き、最も長く律儀に仕えた豊臣家を、秀吉の死後に自らの手で終わらせる。「律儀者」という評判と最も鋭く矛盾する事実（リサーチ §4-3）。善悪で割り切れない——乱世を終わらせた英断か、恩を仇で返した非情か。
  - **B（裏の謎）＝史料批判の縦糸**: 死後、勝者（幕府）が250年かけて「神君家康」像を積み上げた（リサーチ §3-1）。しかみ像・遺訓・伊賀越え・脱糞——美談ほど近年疑問符がつく。「**勝者が作った歴史を、どこまで信じるか**」を子どもに具体例で渡す。日本史上この規模の神格化史料を持つ人物は稀（リサーチ §0・§3）。
  - **BACKLOG 既存案「なぜ待てたか」を採らない理由**（リサーチ §6）: 答えが「我慢強いから」で自己完結し謎として弱く、「我慢強い神君」という英雄像をなぞるだけになりかねない。A+B なら「我慢の末に**何をしたか**（主家を滅ぼした）」「その男が**どう語り継がれたか**（神格化）」まで踏み込める。
- **二つの問いの結び方**: 表の謎（律儀者がなぜ主家を滅ぼしたか＝人間理解）を主線に、裏の謎（神君像をどこまで信じるか＝史料批判）を**手がかり（clue）の縦糸**にする。終章で両者が合流する——「家康が どんな人だったかを 確かめるには、勝者が つくった『神君』の 話を 一度 うたがってみる。それでも 残るものが、ほんとうの 家康だ」。

### 1-2. 四点セット（katsu の骨法をそのまま継承）

katsu で確立した4装置（手がかり clue・信条 creed・えっ！？ spark・**確度の天気マーク◎○△☆**）をそのまま使う。**装置の新規発明はしない**——本作の新規性は「同じ史料批判の器を、本人談（katsu）から勝者の公式史書（家康）へ向け直す」ことにある（§0-3）。

| 装置 | 役割 | 家康での中身 |
|---|---|---|
| **手がかり（clue、全7）** | 裏の謎「神君像をどこまで信じるか」を1章ずつ側面から照らす | **「勝者が作った歴史は、どう積み上がるか」**の7つの気づき。核は「勝った側が歴史を書く」「戒めの絵も遺言も、後の世が作れる（しかみ像・遺訓）」「家に伝わる手柄話は盛られる（伊賀越えの忍者・§3-11）」「神様の位も、前の例を見て選ばれた（神号論争・§3-1）」 |
| **家康のことば（creed、全7）** | 「律儀者／神君」という定着像に対する、行為に即した"正の定義"（こういう時こう動く人だ）。**内心の英雄性でなく行為・かけひきで書く**（katsu の B1 教訓） | 一人称の決め台詞＋象徴アクション。**神格化史料由来の"名言"（東照公遺訓 §3-4）は creed に採らない**（偽作説が有力＝本人の言葉として断定できない）。史実の行為から立てる |
| **えっ！？（spark、章1つ）＋確度マーク** | 「わからないことは宝」。諸説・神格化逸話を好奇心の入口に。各 spark に**確度の天気マーク**を添える | しかみ像「戒めのため」（通説△→記録なし◎の反証）・脱糞逸話（☆・§3-2）・伊賀越えの忍者活躍（○の反証・§3-11）・小早川の劇的寝返り（△・学者が今も論争・§3-10）・東照公遺訓（○偽作説・§3-4）ほか |
| **終章の「きみの答え」** | 集めた手がかりで子ども自身が謎に答える（canon 対象外＝正解を採点しない） | §2 終章。「乱世を終わらせた英断だった／恩を仇で返した非情だった／どちらでもある・立場でちがう／神君の像は盛られているが、260年の泰平を開いた事実は消えない」等。**どれも否定しない** |

**着地の設計（英雄化・悪役化の両回避）**: 終章は「実は語り継がれた通りの神君でした」にも「実は腹黒い策士でした」にも**閉じない**。「神君の 話は 勝った側が 大きく 積み上げた。でも、100年 つづいた 戦の 世が 家康で 終わったのは 事実だ。**盛りを 割り引いても なお 残るもの**——それが、なりきって 確かめる ねうちだ」。

## 3. 視覚文法契約の検証（WRITING 必須＝地図惰性でないことの確認）

WRITING「企画フェーズの視覚文法契約」に従い、**過半の章が『なし／地図（惰性）』でないこと**と、**前作装置の流用に「この人物でも本質に接続するか」の根拠**を明記する。

- **前作装置の流用と根拠**:
  - **確度マーク◎○△☆（katsu 発）**＝本作の背骨。**「この人物でも本質に接続するか」の根拠＝最強のYes**: 家康は神格化史料が突出して多く（リサーチ §0・§3）、貫通の謎 B が「勝者の歴史をどう疑うか」＝確度マークが答えを構成する材料そのもの。katsu（本人談を疑う）と**同じ器を勝者の公式史書へ向け直す**転用で、装置の意味が人物の本質に直結する。
  - **人の図／相関図（kiyomori 発・katsu 4章/5章で使用）**＝章四で主君遍歴（今川→信長→秀吉→滅ぼす）を運ぶ。根拠: A の spine（律儀に仕えた主家を最後に滅ぼす）は関係の連鎖でしか運べない（リサーチ §4-10 が「一本の線」として推奨）。

  - **closeup（kiyomori/katsu 発）**＝章二（三方ヶ原の恐怖）・章六（老いた家康）。根拠: 内心を説明文でなく顔で運ぶ（大目標2の割り切れなさ）。

  - **ルート選択地図（章三）**＝既存の岐路機構＋地図の合わせ技で実装可能か、GO 後の骨組みで検証（新規エンジン拡張が要るなら §10 で人間に諮る）。
