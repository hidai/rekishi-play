## 0. 設計制約（この企画が最後まで守る枠）

1. **史料批判の向きは「本人が一字も残していない人の像は、誰の筆が作ったか」**（リサーチ §0）。5作のどれとも重ならない——hidenaga＝過小評価から救う／kiyomori＝世間の悪役ラベルを剥がす／katsu＝本人談を疑う／ieyasu＝勝者の神話を剥がす／**masako＝そもそも本人の声が無い**。確度マーク◎○△☆（katsu 発）と `HistSource`（史料名＋成立事情）は既存のまま使い、**向きだけ変える**（装置の新規発明をしない）。
2. **裏返しの英雄化をしない**（リサーチ §3-10）。「悪女ではなく実は立派だった」に閉じない。政子は夫の愛妾の家を壊させ、息子を廃し、父を追放した——**行為は事実として残す**。問うのは「同じ行為が男の当主なら何と呼ばれたか」。現代のジェンダー観で断罪も賞揚もしない（CRITERIA B4）。
3. **温度管理が本作最大の執筆難度**（リサーチ §6-3）。子の死が4回＋孫。**死の細部（『愚管抄』の頼家暗殺描写）は主線に出さず、史料批判の装置側（cite / deep）で扱う**。VISION アンチゴール「恐怖・残酷の見世物化」の最前線。
4. **視覚文法は「人の図」。地図は主装置にしない**（リサーチ §5＝鎌倉の主要地点は互いに1〜2km で、WRITING 地図書法4 の最小フレーム ≈392単位に2桁足りない）。政子の力は土地でなく**縁と家**に宿る。→ §3 で章カルテごと検証する。
5. **制度語は deep へ**（合議制・執権・院宣・守護地頭）。ieyasu 章六の A1=3（政治説明量で選択の手応えが落ちた）と同じ穴を踏まない。主線は人で書く（WRITING 書法3）。
6. **ハード境界に非該当**: saveKey は新規 `masako_save_v1`（既存5作のスキーマ不変）。VISION/CRITERIA の改訂も体験予算の緩和も発生しない。§4 の engine 拡張2件はいずれも**能力の追加**で、既存作品の出力を変えない。

## 1. 貫通する謎（riddle）

リサーチ §6-1 の A+B を接続して確定する（ieyasu の骨法を継承）。

> **A（表・主線）** 「**夫と 4人の 子を 見おくった 女が、なぜ、その 子らを うしなう もとに なった 実家（北条）と ならんで、鎌倉を 守りつづけたのか。**」
>
> **B（裏・手がかりの縦糸）** 「**その人の 声は、だれの 筆で のこったのか。**」

- **A** は大目標2（善悪の垣根を超えた人間理解）の縦糸。母であることと、家を続けることが、同じ一人の中で矛盾したまま並んでいる。「実は良い母だった」「実は冷酷な政治家だった」のどちらにも閉じない。
- **B** は大目標1（内発的動機）の駆動輪。政子は**自筆を一枚も残していない**。日本一有名な演説すら、御簾の内から代読された姿（『吾妻鏡』）と、自ら語る姿（慈光寺本『承久記』）で食い違う（リサーチ §3-1）。「政子」という名は1218年の叙位で記録された実名で、生前この名で呼ばれてはいない。「尼将軍」の確認できる初出は**室町時代**（§3-6・§3-8）。**代名詞が2つとも後世製**という人物は稀で、B の答えは章ごとに1枚ずつ手渡せる。
- **BACKLOG 既存案**「なぜ源氏の血が絶えたのに武士の世は続いたのか」は**終章の問いとして B に乗せる**（単独主軸にすると答えが制度論＝説明に寄り、小5に遠い）。
- **終章の着地**: 「政子の 声は 残っていない。だから、この 人が どんな 人だったかは、**きみが 決める しかない**」——正解を採点しない（canon 対象外）。

### 四点セット（既存装置の転用。新規発明なし）

## 4. 要検証3件の結論（リサーチ §8-3。engine を実測した）

### ① relationMap で「章が進むと人が消える」——**やらない。「褪せる」でもなく「切れる」にする**

- 実測: 相関図（`buildRelationMap`）は章でなく**カード取得済み**で出る（`src/engine/map/relationMap.ts:10`、`Relation` 型に章の欄なし）。章で出入りするのは**血の縁の図**（`LineageNode.fromCh` / `LineageEdge.fromCh`、`src/engine/map/figure.ts:315` の `vis`）と**席の図**（`FigureFill.fromCh` の last-wins）で、いずれも「現れる」だけ＝**`toCh` は無い**。
- **設計判断: `toCh` を足して人物ノードを消す案は採らない。** 直近の学び「**欠如は絵で名指せない**」（davinci ch4 の剥落＝読解ペルソナ3案とも失敗し実プレイでも伝わらず撤去）がそのまま当たる。図から人が消えても、読者は**消えたことを認識できない**（前の図を覚えていない）。喪失は「無くなった物」ではなく「**残った物の変化**」でしか運べない。
- **採る形**: `LineageEdge` に **`cutCh?: number`**（この章から、この縁は切れて描かれる＝線を断ち切り／点線化し、両端は残す）を1欄足す。人は図に残る。**切れた線が増えていくことが、政子の生涯の形になる**——義高（1184）・大姫（1197）・頼朝（1199）・三幡（1199）・一幡（1203）・頼家（1204）・実朝と公暁（1219）・義時（1224）。
- 規模: 型1欄＋`figure.ts` の描画分岐1つ＋テスト。既存5作は `cutCh` を使わないので出力バイト不変（`map-labels` / figure スナップショットで pin する）。**無人で可**。

### ② cite に「誰が書いたか」——**拡張不要。既にある**

- `HistSource`（`src/engine/types.ts:143`）が `grade`（史料の時代的近さ）＋ `name`（史料名）＋ `note`（誰がいつ何のために書いたか）を既に持つ。実例: hidenaga `story/index.ts` の `grade:'tale', name:'『太閤素生記』など、江戸時代に書かれた伝記', note:'…のちの世にまとめられた話だ。'`。
- 本作は**同じ場面に source を2つ並べる**使い方（章三の『吾妻鏡』×『愚管抄』、章六の『吾妻鏡』×慈光寺本『承久記』）が要る。1シーンに2枚出せるかは骨組みで確認し、出せなければ**シーンを割る**（WRITING 書法1＝1シーン1つの絵）。型の追加ではなく執筆の割り方で解く。

### ③ 顔エンジンの尼形——**engine に無い。小さく足す（無人で可・要ラスタ目視）**

- 実測: `head` は `eboshi/kanmuri/chasen/kabuto/bozu/zukin/onna/suberakashi/chonmage/sangiri/seibo/nanban/wakamusha/maegami/beret`、`garb` は `western/navy/`既定=着物。**女性の髪型（`onna` 丸髷・`suberakashi` 垂髪）はあるが、尼形（剃髪＋法衣）の語彙は無い**——`src/works/kiyomori/faces.ts` の二位尼が `head:'onna'` で代用し、コメントで "a true 尼 head … is an art gap deferred to attended" と自認している（＝**作者の回避策は engine の欠陥の化石**。JOURNAL 2026-07-23（12）の学び）。
- **採る形**: `head:'ama'`（白い被り物が頭を包み、額の生え際を出さない＝剃髪を直接描かずに尼形を示す）＋ `garb:'houe'`（法衣の襟合わせ）を1つずつ追加。政子は ieyasu 型の2 variant——`@wife`（御台所・垂髪）と基底＝尼形（1199 出家以降）。
- **kiyomori の二位尼にも効く**（既存の attended 積み残しが1件消える）。ただし既存作品の顔を変えるので、`p-tokiko@old` の切替は**別サイクル**に分ける（本作の出荷とは独立の判断）。
- 規模判定: art の**追加**であって描画の大規模改修ではないので無人ループで着手してよい。ただし主人公の顔＝作品の顔なので、**`/visual-check` のラスタ初見読解を必須**にする（顔だけ見て「尼」と読めるか。読めなければ被り物の面積を上げる）。距離フロア（要件①）は追加後に face-audit で再計測する。

## 5. 登場人物（人物カード上限16人・WRITING 書法5）

リサーチ §4 の14人＋比企能員・梶原景時＝**16人ちょうど**。牧の方・一幡・平賀朝雅・一条実雅は**役割語で流す**（「父の 後の 妻」「頼家の 子」）。

- **声を与える（原則4「敵にも声を」）**: 実朝（**唯一、自分の言葉が残った子**＝『金槐和歌集』。政子と正対する）／公暁（父を奪われた子。断罪しない）／後鳥羽上皇（敵役だが歌人・刀工の後援者）／卿二位兼子（章五の対面相手）／時政（切られる父）。
- **1シーン2人まで**の付与規律を守る。16人は上限ぴったりなので、**執筆中に人を増やしたくなったら誰かを役割語に落とす**（骨組みで台帳を作る）。

## 8. パイロットシーン（WRITING 書法10）

**章三「廃する」**（1203 比企の乱→1204 頼家の死）。理由:

1. **本作 register の核が一度に載る**——A の頂点（母が息子を廃す）＋ B の最良の実例（正史が一行、『愚管抄』が生々しく書く＝立場の非対称）＋ 温度管理の最難所（死の細部を主線に出さずに重さを伝える）＋ 人の図の線が初めて切れる。
2. ここが書けなければ他の6章も書けない。**較正点として最も厳しい所を先に測る**。
3. 装置依存が §4 の①（`cutCh`）と③（尼形の顔）の両方に当たる＝**engine 拡張の要否をパイロットで実測できる**。

パイロットが `/eval-work`（離脱自由ペルソナ）を通り、3点未満が無くなってから章一→終章を量産する。
