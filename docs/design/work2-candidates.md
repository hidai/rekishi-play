## 1. 何を測るか（VISION → 評価軸）

VISION の2大目標と設計原則から、候補の適性を次の6軸（各1〜5点）で測る。BACKLOG「人物候補」表の選定基準と同じもの。

| 軸 | 中身 | どの大目標／原則に効くか |
|---|---|---|
| ① 岐路 | なりきって「選べる」人生の分岐が多く鮮烈か。**外した方が面白い**（外れ＝学びの入口）が成立するか | 大目標1・原則1 |
| ② 割り切れなさ | 英雄でも悪役でもない。迷い・矛盾・弱さ・したたかさが濃いか | 大目標2・原則4 |
| ③ 貫通する謎 | その人生の本質を突く一つの大きな「なぜ？」が立つか | 原則2 |
| ④ 諸説の宝 | 史料の欠落・対立が「実はよくわかっていない！」の入口になるか。史料の性格（誰がいつ何のために書いたか）を見せられるか | 原則6・S-D |
| ⑤ 地図 | 移動・地理の広がりがあり、読み解き地図／進軍地図が映えるか | 原則5・体感 |
| ⑥ 入口 | 小5・中1に届く既知性（教科書・大河・お札・ゲーム等）があるか | 原則7・S-C |

**併記する横断論点**（点にはしないが決定に効く）:

- **多様性（ポートフォリオ）**: 第1作は戦国の男性・補佐役（秀長）。VISION は「人間・人生・世界の"まるごと"を一人また一人と増やす」。第2作で**時代・性別・立場**をどれだけずらすかは、作品群としての射程を決める。
- **エンジン適合**: 第1作の装置（顔ジェネレータ＝兜・烏帽子など戦国の被り物中心、進軍地図＝戦国大名の領国拡大）が、その人物にどれだけ流用できるか。近代・女性・非武人は新規描画の投資が要る。
- **campaignMap の作品結合**: 現状 `src/engine/map/campaignMap.ts` は秀長のルートキー・勢力名を直書き（BACKLOG「未整理」）。**どの候補でも骨組み着手前に解消が要る**。地図の性格が戦国と大きく違う候補（渋沢・勝）は、その解消がより大掛かりになる。

## 2. 候補カルテ

各候補の点は「秀長という到達点」を基準にした相対評価。**高い＝良い候補**ではなく、**低い軸＝設計で埋める課題**として読む。

### 北条政子 — 尼将軍

- **貫通する謎（精緻化案）**: 「なぜ、夫（源頼朝）の血筋は3代で絶えたのに、政子の支えた武士の世（執権政治）は続いたのか」（武家政権はこの後およそ700年続く、を背景に置く）。副案: 「なぜ息子たちを次々に失いながら、鎌倉を守る側に立ち続けたのか」。
- **割り切れなさ**: 実子・頼家の追放、実朝の暗殺と源氏の断絶に、北条一族の当事者として関わる。**母でありながら我が子より"家"を選ぶ**構図は、大目標2（善悪を超えた人間）の最強クラス。承久の乱の演説で御家人を束ねる指導力と、肉親を失い続ける女の情念が同居する。
- **岐路の例（外れ＝学びの入口）**: ①伊豆の流人・頼朝との結婚を、父・時政の反対を押し切って選ぶか ②頼家と実朝、どちらの側に立つか ③承久の乱で、朝廷に弓を引くか退くか。「我が子を取るか、家を取るか」という重い分岐が置ける。
- **諸説の宝**: 実朝暗殺の黒幕、頼家の死の真相、承久の乱の演説の実在性——いずれも主史料『吾妻鏡』が**北条得宗家に都合よく編まれた**ことに起因する。「勝者が書いた記録」を、政子＝勝者側から裏返して見せられる希少な題材。
- **地図**: 伊豆（蛭ヶ小島）・鎌倉・京（承久の乱）・奥州。**鎌倉中心で狭い**（BACKLOG も指摘）。局所地図＝御所・幕府・御家人の館の配置図など、"広がり"でなく"関係の地図"で見せる工夫が要る。
- **入口**: 教科書の「尼将軍」「承久の乱の演説」。大河『鎌倉殿の13人』（2022）で知名度上昇。**女性主人公1号**。
- **リスク**: (a) 女性主人公はエンジンの被り物・鎧中心の顔／演出を要調整。(b) 暗殺の連続を小5にどう出すか（恐怖・残酷の見世物化を避ける＝アンチゴール）。(c) 地図が狭い。
- **点**: ①4 ②5 ③5 ④5 ⑤3 ⑥4

### 勝海舟 — 幕臣にして幕府を畳んだ男

- **貫通する謎（精緻化案）**: 「なぜ幕臣（幕府の家来）なのに、幕府を終わらせる側に回れたのか」。副案: 「なぜ敵の大将（西郷）に、江戸の町を託せたのか」。
- **割り切れなさ**: 幕府を守るべき身でありながら開国・倒幕の現実を受け入れ、旧幕臣からは「裏切り者」とも見られた。敵将・西郷隆盛との信頼で江戸無血開城を成す＝「敵に信を置く」人物。
- **岐路の例**: ①咸臨丸で太平洋を渡り世界を見るか ②神戸海軍操練所に、脱藩の志士（薩摩・土佐）まで受け入れるか ③江戸で薩長軍を迎え撃つか、明け渡すか。
- **諸説の宝**: 海舟本人の談話『氷川清話』『海舟座談』は**自慢・脚色が多い**ことで有名。「本人が語った歴史をどこまで信じるか」＝史料批判を主題に据えられる最良の教材の一つ。無血開城も山岡鉄舟の先行交渉など実相に諸説。
- **地図**: 江戸〜長崎（海軍伝習所）〜**太平洋横断（サンフランシスコ）**〜神戸〜京。**海と世界に開く**＝地図が映える。海路・蒸気船の演出が新機軸。
- **入口**: 教科書（江戸無血開城・咸臨丸）。ただし幕末の政治構造（薩長土肥・幕府・朝廷）は人物関係が複雑で、小5には道しるべが要る。
- **リスク**: (a) 幕末政治の複雑さ＝小5への翻訳が難所。(b) 洋装・蒸気船＝エンジンの faces/art（戦国仕様）を近代へ拡張する投資。
- **点**: ①5 ②4 ③4 ④5 ⑤5 ⑥3

### 渋沢栄一 — 財閥をつくらなかった男

- **貫通する謎（精緻化案）**: 「なぜ『日本一の金持ちになれたはずの男』は、自分の財閥をつくらなかったのか」。
- **割り切れなさ**: 攘夷の志士（高崎城乗っ取りを企て、**決行寸前で中止**）→一橋家→幕臣→パリ→新政府→下野して民間へ。身分と立場を横断し続ける。独占（財閥）でなく「合本主義」を選んだ動機は、欲望と公益のあいだの葛藤。ただし「日本資本主義の父」という**聖人化の罠**は要警戒。
- **岐路の例**: ①攘夷テロを決行するか、思いとどまるか（外れ＝学びの入口の好例）②幕臣として幕府に殉じるか、新時代へ移るか ③官（大蔵省）に残るか、民間に賭けるか ④富を独占するか、分けるか。
- **諸説の宝**: 渋沢は**記録魔で史料が非常に豊富**＝「よくわかっていない」の入口は**むしろ乏しい**（④が弱い）。論点は『論語と算盤』『合本主義』の解釈という思想面に寄る。
- **地図**: 血洗島（深谷）→江戸→京→**パリ・欧州（万博）**→東京。海外は新鮮だが、近代の舞台は鉄道網・都市・会社で、**戦国の進軍地図（領国拡大）の文法が使えない**（BACKLOG「地図の文法が変わる」）。絵作りの再発明が要る。
- **入口**: **新一万円札（2024〜）**・大河『青天を衝け』（2021）で知名度急上昇。「お札の人」は小5にも強い。
- **リスク**: (a) 面白さの核が政治・軍事でなく**経済判断**＝岐路を小5に翻訳するのが難所。(b) 史料豊富ゆえ「わからないことは宝」が薄い。(c) 近代の絵・地図を新規開発。
- **点**: ①5 ②3 ③5 ④3 ⑤3 ⑥5

### 平清盛 — 悪役と語り継がれた開拓者

- **貫通する謎（精緻化案）**: 「なぜ『おごれる悪役』として語り継がれた男が、海の道（日宋貿易）を開けたのか」。副案: 「なぜ武士なのに貴族のようにふるまい、その貴族に憎まれたのか」。
- **割り切れなさ**: 『平家物語』が「驕り→滅び」の教訓譚として造形した悪役像を、**海運・貿易を切り開いた先駆者**として裏返す。大目標2「英雄にも悪役にもしない」を、**すでに世間が貼った"悪役"ラベルを剥がす**形で正面から扱える。
- **岐路の例**: ①保元・平治の乱で、どの主に付くか ②後白河院と、協調するか対立するか ③宋との貿易という前例なき賭けに出るか ④福原（神戸）への遷都を強行するか。
- **諸説の宝**: **主史料『平家物語』は平家滅亡後に成立した語り物**で、平家を教訓の題材に造形した色が濃い（作者・成立は諸説）。「後世が敗者をどう物語にしたか」＝史料の性格を教える最良の教材。清盛出生（白河院落胤説）・日宋貿易の実態・福原遷都の評価にも諸説。
- **地図**: **瀬戸内海（大輪田泊＝現・神戸、厳島、音戸の瀬戸）・博多〜宋・京・福原**。海の道と瀬戸内＝地図が映える。戦国の陸の進軍地図とは別に「海路・交易路」の地図文法が立つ。
- **入口**: 教科書（日宋貿易・厳島神社・武士初の太政大臣）。大河『平清盛』（2012）。『平家物語』冒頭は中1国語の定番。「おごれる人も久しからず」の物語性で小5も入れる。
- **リスク**: (a) 院政期の権力構造（院・摂関・武士）が小5に複雑。(b) 似た名前（清盛・重盛・後白河・崇徳）の整理。(c) 保元・平治の乱の殺伐をどう見せるか。
- **点**: ①4 ②5 ③5 ④5 ⑤5 ⑥4

### 徳川家康 — 待った男

- **貫通する謎（精緻化案）**: 「なぜ律儀者と言われた男が、最後に主家（豊臣）を滅ぼしたのか」。BACKLOG 案「なぜ待つことができたのか」は**答えが『我慢強いから』で閉じやすく**、謎としてはやや弱い。
- **割り切れなさ**: 人質の少年から天下人へ。だが**東照大権現＝神格化**の史料バイアスが強烈で、**脱・英雄化が最も難しい**（VISION アンチゴール「英雄化」に真っ向から抵触しうる）。方広寺鐘銘事件〜大坂の陣の非情を、断罪も美化もせず出せるかが勝負。
- **岐路の例**: ①桶狭間の後、今川から独立するか ②三方ヶ原で武田に討って出るか籠るか（大敗＝外れの宝）③秀吉に臣従するか戦うか ④関ヶ原で東軍を率いるか。岐路は最多クラス。
- **諸説の宝**: 史料は豊富だが神格化史料（『東照宮御実紀』）のバイアス、三方ヶ原の脱糞逸話、影武者説（俗説）など、史料批判の題材にはなる。
- **地図**: 三河→駿河→遠江→関東（江戸）→関ヶ原→大坂。移動が広く、**秀長の進軍地図文法がほぼそのまま使える**（エンジン適合は最良）。
- **入口**: **既知性は全候補で最高**（教科書・大河『どうする家康』2023 ほか多数）。
- **リスク**: (a) 既知の「天下人・英雄」像が強すぎ、VISION の「英雄にしない」を最も損ないやすい。(b) **第1作（秀吉の弟・戦国）と時代・題材が近接**＝作品群としての多様性が最も乏しい。
- **点**: ①5 ②3 ③3 ④4 ⑤5 ⑥5

## 4. AI 一次評価と推薦（決定は人間）

**総合の見立て**: VISION の核（貫通する謎・善悪を超えた人間・諸説の宝・映える地図）に最も素直に乗るのは **平清盛**、作品群の**多様性**と大目標2の鋭さで拮抗するのが **北条政子**。この2つを一次推薦とする。

- **第1推薦: 平清盛** — ③④⑤② が軒並み高く、**弱い軸（3点未満）が無い**。「世間が貼った"悪役"ラベルを、なりきりで剥がす」構図は大目標2そのもの。海の道の地図は第1作と別の映え方をし、平安末という**別時代**で作品群の射程を広げる。難所（院政期の複雑さ）は人物関係の道しるべ（原則7）で埋められる範囲。
- **第2推薦: 北条政子** — **女性主人公1号**という多様性と、「母か家か」という大目標2の鋭さは他候補にない。地図の狭さ（③⑤の弱点）を「関係の地図」で設計しきれるかが分かれ目。ここが解ければ最有力にもなりうる。
- **単騎の強みで残す: 勝海舟** — 「本人の語り（『氷川清話』）をどこまで信じるか」を主題化できる、**史料批判の教材として突出**。地図も海・世界で映える。幕末政治の複雑さ（⑥3）を小5に翻訳できるかが条件。
- **推すが留保: 渋沢栄一** — 謎と既知性は強いが、④（諸説の宝）が薄く、面白さの核が経済判断で小5への翻訳が難所。地図・絵の文法を新規開発するコストも大きい。「近代」を作品群に入れる価値と天秤。
- **今回は非推奨: 徳川家康** — 既知性は最高だが、**英雄化リスクが最大**（VISION アンチゴール直撃）で、かつ**第1作と題材が近接**し多様性が最も乏しい。3作目以降、英雄像を崩す設計に自信が持ててからの方が VISION に忠実。

**トレードオフの言語化（人間が選ぶ軸）**:

- 「VISION の装置に一番きれいに乗る／別時代で射程を広げる」を重んじる → **清盛**
- 「主人公の多様性（女性1号）と大目標2の鋭さ」を最優先 → **政子**
- 「史料批判そのものを主題化したい」 → **勝海舟**
- 「近代・経済という新領域に踏み出したい」 → **渋沢**
