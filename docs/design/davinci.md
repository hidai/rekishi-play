# 企画探索 — レオナルド・ダ・ヴィンチ（外国人第1候補 `davinci`）

> **位置づけ**: これは **AI による設計探索**であり、企画確定書ではない。**人物を「次作にする」決定は人間**が下す（VISION 役割分担）。第1の**外国人**候補として、VISION 由来の基準で適性を評価し、実装できる粒度まで設計を起こしておく。
> **本文書の核は人物ではなくエンジン拡張**。提案の中心＝「観察ビュー」＋「つながり図鑑」は**地図に依存しない汎用装置**で、レオナルドを採らなくても他作品（科学者・探検家・職人）に効く。だからこの探索は「レオナルド賭け」ではなく「新しい見せ方の仕込み」として読める。
> **史実は通説レベルの一次知識で、出典検証は未了**。GO が出たら `docs/research/davinci.md` で出典つきに固める（既存パイプライン踏襲）。断定を避け、逸話は「伝説」と明示する。
> **設計の拠り所**: 憲法 [../VISION.md](../VISION.md)、第1作で確立した装置（README.md）、`Work` 契約（`src/engine/types.ts`）。

## 0. 設計制約とハード境界の所在

- **ハード境界に抵触しない**。①セーブ: davinci は**新規 saveKey（`davinci_save_v1`）**で、既存 `hidenaga_save_v1` スキーマに触らない。②③VISION/CRITERIA 改訂・体験予算緩和は本企画では発生しない。→ **観察ビュー・つながり図鑑・世界地図拡張はすべて AI 自律の範囲**（エンジン拡張＝ハード境界ではない）。
- **人間判断点は2つだけ**（§10 に詳述）: (a) そもそもレオナルドを作品にするか、(b) センシティブ題材（解剖＝死体・レオナルドの性的指向）の扱い方針。
- **地図拡張の土台は既に有る**: BACKLOG「地図エンジン Phase 2」で緯度経度＋実行時可変投影・海外海岸線焼き込みが済んでいる（`src/engine/map/project.ts`・`src/shared/geoWorld.ts`・`scripts/build-overseas-coastline.mjs`）。**欧州・イタリアへの拡張は「式の変更」でなく「大陸をクリップして bbox から投影を導く」2点で足りる**（Phase 2 の学び）。地図は障害でない。
- **`{@html}` 信頼境界を守る**: 観察キャプション・つなぎの一言・カード本文は静的手書きデータに限る。実行時外部入力（URL・ユーザー文字列・fetch）を Work データに混ぜない（既存規約）。

## 1. なぜレオナルドか（VISION → 適性）

VISION の2大目標・6原則に照らす。点は「秀長という到達点」基準の相対評価（高い＝良いではなく、低い軸＝設計で埋める課題）。

| 軸 | 見立て | 中身 |
|---|---|---|
| ① 岐路 | 5 | フィレンツェ→ミラノ→ボルジアの軍師→ローマ→フランス。**画家か軍事技師か**、**芸術か戦争か**（青銅像が大砲に鋳つぶされる）、**暴君チェーザレに仕えるか**。外した方が面白い岐路が濃い。 |
| ② 割り切れなさ | 5 | 私生児・独学・左利き・菜食。**平和を願いながら戦争兵器を設計する矛盾**。天才なのに**ほとんど完成させない**。英雄でも悪役でもない「人間まるごと」。 |
| ③ 貫通する謎 | 5 | 「**なぜ、なんでもできた天才は、ほとんど"完成"させなかったのか？**」——人生の本質を一言で突く。 |
| ④ 諸説の宝 | 5 | モナ・リザは誰か／有名な「名言」の誤帰属（本物は手記から取る＝`docs/research/davinci.md` §3-6）／王の腕の中の最期（伝説）／手記の鏡文字。**史料批判そのものが遊びになる**。 |
| ⑤ 地図 | 3→4 | 領土の広がりは無いが、**宮廷から宮廷への旅＝社会の地図**として映える。しかも第5章でレオナルド自身が**都市図（イモラ）を描く**＝地図が主人公の作品になる。 |
| ⑥ 入口 | 5 | モナ・リザ・空とぶ機械・解剖図。**子どもの初速は全候補中でも最上位**。 |

**多様性（ポートフォリオ）**: 第1〜4作は日本・戦国〜近代。レオナルドは**ルネサンス・欧州・芸術家/科学者**＝時代も地域も職業も大きくずらす。作品群の射程を一気に広げる。

**大目標2への直撃**: レオナルドが教えるのは事実でなく**「見る」「つなぐ」という考え方そのもの**。善悪を超えて「人間・世界」を学ぶ、の最良の器。

## 2. 中心メタファーの張り替え（地図＝領土 → 手記＝つながりの網）

秀長作品の中心の絵は「進軍の地図（領土の広がり）」だった。レオナルドでは中心が根本から変わる。

| | 秀長 | レオナルド |
|---|---|---|
| 一生の本質 | 権力がどう広がるか | **一つの頭が、世界をどうつなげたか** |
| 中心の絵 | 進軍の地図（領土） | **手記（コーデックス）＝つながりの網** |
| 育てるもの | 兵・領国（力） | **「気づき」（見たものの数）** |
| 中心の動詞 | 選ぶ・攻める | **観る・つなぐ** |

**地図は捨てない。主役から「今どの宮廷にいるか」の道しるべ役へ降格**させ、代わりに**観察と連結**を魂に据える。UI 全体を「レオナルドの手記を解読し、埋めていく」体験として枠づける（セピア線画＋ハッチング＋古紙。closeup と同じ固定パレット純 SVG）。

## 3. 貫通する謎と creed

**謎の核**:
> **「なぜ、なんでもできた 天才は、ほとんど"完成"させなかったのだろう？」**

- 各章の**手がかり**＝「なぜ終わらないか」の側面（つなぐほど問いが3つ増える／見ることが仕事だった／すべてがつながって"完"が無い）。
- **答えは子どもが出す**（VISION「判断は子どもに残す」）。終章、**自分が育てた星座**を見て「完成しなかったんじゃない。つなぎ続けたんだ」と気づく——**未完＝失敗の反転**を、説明でなく自分のグラフで悟らせる。
- **creed（信条・一人称の決め台詞＋象徴アクション。史実断定は避け「——気がした」等で創作明示）案**:
  - 「おれは、仕上げるためでなく、知るために描く。」
  - 「鳥がなぜ飛ぶかを知れば、人も飛べる。」
  - 「行き止まりはない。すべてはつながっている。」

**貫通する謎の"答え"を、機構が体感させる**のが本企画の勝ち筋（§4-6）。つなぐほど星座が爆発的に育ち、子どもは「終わらなさ」を自分の手で体験する。

## 4. 核のエンジン拡張① 観察ビュー（find-on-image）

READMEが予告する「将来 findOnMap 等」の本命。**読み解き地図の代わりに、高精細な手記の絵を指で探り、レオナルドが気づくものを集める**。

### 4-1. ワイヤーフレーム（縦持ち）

```
┌──────────────────────────────┐
│ ← もどる      気づき 2/5   🔊 │   トップバー（流用）
├──────────────────────────────┤
│                              │
│     [手記の絵・セピア線画]      │   buildObserve() 純SVG・固定パレット
│         ◯ 虫めがね            │
│        （指で なでる）          │
│            ✦                 │   レンズ下で細部が解像
│                              │
├──────────────────────────────┤
│  ● ● ○ ○ ○      [気づきトレイ] │   進捗ドット＋採集トレイ
└──────────────────────────────┘
        [つづき →] （必須2つで解錠）
```

### 4-2. 中心操作「虫めがねをなでる」

自由ピンチでなく、**指に追従する虫めがねレンズ**。レンズ下の線画が blur→sharp に解像し、**本物の観察対象が来ると ✦ が灯り、鏡文字のキャプションがちらつく → タップで採集**。「見る＝注意を向ける労力」を身体化し、探しやすさも解決する（なでれば出る）。低スペック／`prefers-reduced-motion` では離散タップ→レンズにフォールバック。

### 4-3. 状態機械

| 状態 | 契機 | 遷移先 |
|---|---|---|
| IDLE | ポインタ down | SWEEPING |
| SWEEPING | レンズが有効対象へ重なる | HOVER_HOTSPOT |
| SWEEPING | レンズが**gate 未解錠**対象へ重なる | GATED_HINT（「まだ この目では見えない…」淡い ?） |
| HOVER_HOTSPOT | タップ | COLLECTING |
| COLLECTING | アニメ完了 | DISCOVERED（✎点が残る・再タップで再読） |
| （any） | 必須数 達成 | COMPLETE → 「つづき」解錠 |

### 4-4. 採集アニメ（約900ms）

- 0ms: レンズ環パルス（1→1.15→1）
- 0–250: 対象へパンチズーム（`transform-origin`=hotspot, ~2.2x）
- 200–650: キャプションが**鏡文字で右→左に書かれ**、650ms で水平反転して可読に（`scaleX:-1→1`＋紙のシマー）
- 650–900: 細部クロップがサムネ化しトレイへ弧を描いて飛ぶ、ドット ● 充填。必須達成で「つづき」がせり上がる

### 4-5. SFX（Web Audio 合成・既存 sfx.svelte.ts の語彙）

なで＝低い紙擦れ／解像＝高いシマー（正弦2倍音・速い減衰）／採集＝既存カード獲得マリンバ／gate＝抑えた低い soft／必須達成＝上昇する琴アルペジオ。

## 5. 核のエンジン拡張② つながり図鑑（graph collection）

集めた気づきがノードになり、**ドラッグで重ねると本物の連関だけ線が灯り、発明が生まれる**。配列でなく**初のグラフ型コレクション**。**VISION を最も深く実現する装置**——「知識＝つながった網」という**レオナルドの思考法そのものを子どもにインストールする**。

### 5-1. ワイヤーフレーム（縦持ち）

```
┌──────────────────────────────┐
│ ← 手帳   つながり 4/?  ★2  🔊 │
├──────────────────────────────┤
│   ✦水────✦髪                 │   灯った辺＝ハッチング線
│     ＼                        │
│      ✦鳥───[空とぶ機械]★      │   発明ノード
│                              │
│   ✦光──✦スフマート★          │
│   ○（未発見スロット）          │
├──────────────────────────────┤
│ ヒント：にた かたち を かさねてみよう│   序盤だけ
│        [全体を見る]           │   buildLocator 流用の fit
└──────────────────────────────┘
```

### 5-2. 中心操作「星を星へドラッグ」（＋二タップ代替）

星を持ち上げると**光る綱（tether）が指を追う**。他ノードに重ねて離す。**二タップ（元→先）を a11y／小さい指の第一級代替**として用意（reduced-motion でもこちら）。**可能な辺は事前に見せない**（穴埋め作業にしないため）。子どもが「微笑みは川に似てる?」と**自分で仮説を持って試したくなる**＝内発的動機の核。

### 5-3. 状態機械

| 状態 | 契機 | 遷移先 |
|---|---|---|
| BROWSE | 星タップ | 詳細カード／辺タップ→一言バブル |
| BROWSE | 星 down | DRAG_START（星が浮く） |
| DRAGGING | 候補ノードへ接近 | OVER_TARGET（両方 glow・綱が張る） |
| OVER_TARGET | 離す（本物の連関） | EDGE_BORN |
| DRAGGING/OVER | 離す（非連関・空） | RELEASE_INVALID |

**序盤（1–2章）だけ** DRAGGING 中に**唯一の正解ターゲットが淡く脈動**＋コーチ文。中盤は脈動なし＝自由な仮説。終章はサンドボックス（「まだつながっていない星:N」は誘うだけ・強制しない）。

### 5-4. 辺誕生アニメ（約1200ms）

- 0ms: 両ノード白フラッシュ
- 0–350: A→B にインク線が `stroke-dasharray` で描き足される（羽ペン音）
- 350–600: 一言が鏡文字→反転で羊皮紙リボンに書かれる
- **発明の場合** 600–1000: 線の中点に新しい星が bloom（scale 0→1）→カードめくりで発明カードへ、琴の和音
- 1000: つながり +1／★。この辺が章の手がかりなら**既存の手がかり通知を発火**

### 5-5. 非連関（約500ms・罰なし）

綱が弾性で元へ戻り、「まだ、つながらない…かも?」をトースト。**カウンタ不変・レオナルドが肩をすくめる**＝仮説→検証を促す。科学の方法が遊びになる。

### 5-6. SFX

有効辺＝羽ペン描き＋琴和音／発明 bloom＝マリンバ＋琴の重ね（章クリア系を弱く）／非連関＝ごく soft な「ふっ」（または無音）。

## 6. 3種のノードと「目が育つ」再訪機構

### 6-1. ノードは3種類

| 種類 | 何 | 生まれ方 | 既存資産 |
|---|---|---|---|
| **気づき（observation）** | 観た最小単位（水の渦・鳥の傾き・光と球・筋肉の束・髪のカール） | 観察ビューでタップ発見 | 分野色で星座に配置 |
| **つなぎ（insight edge）** | 分野をまたぐ連関＋レオナルドの一言 | **子どもがドラッグで作る** | — |
| **発明・作品（invention）** | 気づき×つなぎが生む成果（空とぶ機械・スフマート・心臓の渦） | 鍵連結の完成で出現 | **既存カード機構に載せる** |

### 6-2. 観察は"目"が育つ（＝最重要の再訪機構）

hotspot は**前提ノードで gate**できる。第2章で「光と球」を知って初めて、第6章のモナ・リザで**「ほほえみのふち＝ぼかし」が見える**。さらに——

> **昔の絵に戻ると、今の目で新しい発見が出る。**

第1章の川の絵は、章が進むと「渦」「葉脈」が後から見えてくる。**観察力そのものが育成メーター（「気づき」）になり、再訪が飾りでなく機構的に報われる**。VISION「収集と再訪」を、コスメでなくゲームプレイで実装する。メーターは力・暴力でなく**知覚**を育てる＝レオナルドにふさわしい育成実感。

## 7. 章構成（章×装置の対応）— たたき台（全7章 `totalChapters:7`）

貫通する謎「なぜ完成させないか」の手がかりが各章で1つ積もり、終章で子どもが答えを出す。

| 章 | 山場 | 主装置 |
|---|---|---|
| 一 ヴィンチ村の私生児（1452〜） | 左利き・鏡文字・最初の観察（洞窟／川） | 観察ビュー導入＋鏡文字＋ステージ「きみ＝レオナルド」 |
| 二 フィレンツェの工房（ヴェロッキオ） | 師を超えた天使（伝説）＝光と影 | 描く体感（chiaroscuro ドラッグ minigame） |
| 三 ミラノ売り込み（スフォルツァ） | **画家でなく"軍事技師"として売り込む手紙**／巨大馬像 | 選択：芸術か戦争か＋社会相関マップ |
| 四 最後の晩餐 | 実験画法ですぐ傷む | 観察＋えっ！？「なぜ名画はすぐ傷んだ？」 |
| 五 チェーザレ・ボルジアの軍師 | 暴君に仕える最も暗い岐路／**イモラ都市図を描く** | ここで地図が主人公自身の作品として輝く＋矛盾の頂点 |
| 六 モナ・リザと解剖 | 微笑（sfumato）・解剖・飛行への挑戦 | sfumato なぞり＋**つながり図鑑が一斉点灯** |
| 終 フランス、最期（〜1519） | 王の腕の中で（伝説→創作明示） | 対面の場（closeup）＋creed 総括＋**未完の図鑑が完成**＋隠しページ「もしノートが当時ぜんぶ実現していたら」 |

### 一枚で見る：第六章「モナ・リザと解剖」

**観察ビュー**＝1枚の「習作ページ」に、水の渦・風に傾く鳥・髪のカール・肩の筋肉（線画・残酷描写なし）・微笑みのふち。子どもが作れる**つなぎ**：

- 髪のカール × 水の渦 →「かみの毛は、水のながれと同じうずをえがく」（純粋な"あっ"）
- 水の渦 × 血のながれ →「心の中の血も、川のように渦をまく」→ **発明「心臓のしくみ」**（史実：大動脈弁の渦を数百年先取り＝最高の「えっ！？」・諸説として枠づけ）
- 鳥の傾き × 空気のうず → **発明「空とぶ機械」カード**
- 微笑みのふち × 光と球（2章） → **技「スフマート」** → ここから **sfumato なぞり minigame が起動**

観察・星座・ミニゲームが**互いに噛み合う**（1枚の絵が3機構の入口）。

## 8. 既存資産の流用と、新規に要るもの

**ほぼ無改修で流用**:

- 似顔絵ジェネレータ（`faces.ts`）＝ルネサンスの被り物（ベレー帽・ボンネット）を FaceSpec に追加するだけ。剃髪・ひげ・虹彩色は既存パラメータ。人物：レオナルド／ヴェロッキオ／ルドヴィコ・スフォルツァ／チェーザレ・ボルジア／宿敵ミケランジェロ／弟子サライ・メルツィ／フランソワ1世。
- 対面の場（`closeup`）＝モナ・リザが座る場、フランソワ王の館の最期。
- reveal（危機の全画面）＝**巨大な青銅像が大砲に鋳つぶされる**／フランス軍侵攻。
- creed・quiz・meters・SFX・選択→もしも・**「えっ！？図鑑」（sparks）**＝レオナルドはこれの宝庫（モナ・リザは誰？　王の腕の中の最期は本当？　手記はなぜ鏡文字？）。
- 社会相関レイヤー＝欧州地図に、パトロン/好敵手の辺を重ねる。既存の「顔を場所に置く＋タップで人物カード」機構がそのまま乗る。

**新規に要るもの（優先順）**:

1. **観察ビュー**（`Scene.observe` ＋ `src/engine/observe.ts` 純ロジック ＋ `buildObserve` art ＋ `ObserveScreen`）
2. **つながり図鑑**（`src/works/davinci/graph.ts` データ ＋ `src/engine/graph.ts` 純ロジック ＋ `ConstellationPane` ドラッグ UI）
3. **鏡文字リビール**（CSS transform＝安い・手ざわり高）
4. **物理を手で感じる minigame**（既存 'sort' に光と影ドラッグ／sfumato なぞり／遠近法グリッドを追加）
5. **未完の図鑑**（「完成品」でなく「なぜ途中でやめたか」を集める＝報酬の反転。ほぼデータ）
6. **世界地図**（欧州・イタリア。Phase 2 の geoWorld を配線）

## 9. データモデルとエンジンの粒（テスト可能性を守る）

- `Scene.observe?: ObserveSpec` — `{ artId, hotspots: [{ id, nodeId, region, caption /* ruby HTML */, gatedOn?, essential? }] }`。art は純 SVG builder `buildObserve(artId)`（固定パレット・`<defs>`/`id` 不使用＝closeup と同じ規律）。
- `src/engine/observe.ts` — 可視 hotspot 判定・進捗・「つづき」gate（純関数）。
- グラフは**作品データにノード/辺**（`src/works/davinci/graph.ts`）、`src/engine/graph.ts` が「灯る辺」「ドラッグの妥当性」を純判定。**辺は全て手書き**（非連関は「書いていない」だけ＝gentle-fail）。**制作コスト＝本物の連関の数**で N² に増えない＝中身そのものだから健全。
- **ドラッグの綱だけは SVG 文字列に入らない**: builder が**ノード id→座標の幾何を純関数で返し**（決定的・テスト可能）、薄い Svelte 層がヒットテストと綱の数式に使う。綱は `{@html}` の上に絶対配置 SVG 線として重ねる。**幾何は純粋、はかない drag 状態だけコンポーネント**。
- クリック委譲は地図の `.mapface[data-pid]` に倣い `.starnode[data-nid]`・`.staredge[data-eid]`。
- **セーブ**: `Profile` に `observed: string[]`・`links: string[]` を足す。**davinci は新規 saveKey ゆえ設計自由**（自動保存はせず `EDGE_BORN` 後に明示 `persist()`＝既存規約）。
- **目視/回帰**: `render-observe.ts`／`render-constellation.ts` を追加、`visual-coverage` と同様の coverage test で in。
