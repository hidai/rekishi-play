# WRITING — 執筆規律（教材コンテンツの書法）

CRITERIA は書いた後の判定、ここは書く前・書く最中の規準。

**緩める変更はハード境界**（CLAUDE.md）。厳格化・計測追加は自律で可。経緯は git ／ JOURNAL-archive。

## 書法（シーン主線の14か条）

1. **1シーン＝1つの絵＋1つの感情＋1つの声。** 2つ目の話題が入りそうになったら、シーンを割るか deep へ出す。
2. **感情は要約しない。** 「〜という悲しい出来事だった」と地の文で説明しない。声（`.speak`）・monologue・場面の細部（手・目・音）で感じさせる。
3. **説明は本文に置かない。** 制度・経緯・用語の解説は deep へ。本文の括弧注釈（「安芸＝今の広島…」）は最小限に——注釈が要る語は、そもそも主線に出しすぎのサイン。
4. **主線は熱く、留保は装置で。** 「と伝わる」等のヘッジ・史料メタ視点は spark / deep / cite / hist の仕事。主線に混ぜない。創作明示の「——気がした」（G7 様式）は対象外。**人物への評価語（暴君・悪人…）だけはヘッジでなく帰属で持つ**——「」でくくり、だれがそう呼ぶかを書く。**選ぶ前に浴びる面（問い・選択肢）と恒久ラベル面では裸で使わない**＝判定を先に渡さない。機械検査＝`tests/epithet-attribution.test.ts`。
5. **人は絞る。** 人数の上限は予算表。本文に「名前だけの人物」を出さない——役割語（「院の側近」）で流すか、出すなら声かひっかかりを1つ与える。
6. **本文は短く。** 字数の上限は予算表。迷ったら削る（網羅しないはアンチゴールが許可済み）。
7. **章の山場は本文以外が語る。** 各章に「本文の代わりに語る装置」（地図・closeup・reveal・図など）を企画の章カルテで先に決める。装置が「なし」の章は、書く前に装置を用意する。
8. **選択は分岐で報いる。** どちらを選んでも同じ文面に合流させない。最低でも monologue 一拍か hist の差で「選んだ意味」を返す（VISION 原則1・3の実務）。
9. **小5の音読でリズムを確かめる。** 一文は短く。文語調（「〜ざるを得ない」）・抽象語（「像の下地」）は、小5が音にして意味が届くかで判定する。
10. **パイロットシーン制。** 新作品は全章執筆の前に代表1シーンを最終レジスタで書き、`/eval-work` を通してから量産する（その register が作品の基準）。
11. **前提は作品の中で着せる。** 「有名な」「世にいう」で読者の既知に寄りかからない。裏返してよいのは読者が**作中で持たされた**思い込みだけ＝①読者の選択 ②遊んだ場面 ③作中人物の口。載せられない通説は主線に出さず deep・手帳へ。**裏返す前に、着せる。** 機械検査＝`tests/known-premise.test.ts`。
12. **外側の声は、なりきりの息継ぎでだけ話す。** 史料メタ・現代からの相対化・「じつは」は、選択の後（hist）・章のおわり・手帳で話す。物語の途中で読者の肩をたたかない。まだ遊んでいない章の山場を先に明かさない。
13. **制度語は、その場で一句で言い換える。** 幕府・身分・石高…＝**読めるのに意味が届かない語**。主線に出すならその画面のうちに一句そえ、**言い換えられないなら主線から降ろす**（注釈で埋めるのは説明への逆戻り）。同じものを2つの語で呼ばない（侍／武士）。**同じ人を面ごとに別の名で呼ばない**——改名は ①作中の出来事 ②章の枠（lead）③「——のちの X」の順で結ぶ（③は最後の手段＝12 と衝突）。名を並べるだけは結びでない。機械検査＝`tests/institution-gloss.test.ts`・`tests/name-continuity.test.ts`。
14. **因果を省略しない。** 結果だけ書いて「なぜそうなったか」の一文が無い画面を作らない。**書き手の頭にある一文がいちばん抜けやすい**——読者は前の画面までしか読んでいない。書法3 が deep へ出すのは語の説明で、**その画面が起きた理由は主線の骨**。埋めるのは ①その場の一句 ②人物の声 ③選択の hist。一文で書けない因果は結果ごと降ろす。機械検査は無い（`/eval-work` 読み通しペルソナ）。

## 地図・図の書法（主ビジュアルの規律）

シーン地図・figure・closeup も執筆物として、この規律で書く（実例は git）:

1. **開幕にアンカーする。** 地図は本文より先に目に入る establishing shot——読者が最初に立つ場面を表し、まだ読んでいない結末を先に見せない（例外＝シーン自体が結末を主題とする むすび・reveal・臨終）。回想では時間の手がかり（「〜の 前の 年」）を本文と地図の両方に置く。
2. **地図はヘッジできない——「解像度 vs 係争幅」で判定する。** マークが係争（諸説の幅）を解像するなら、それは断定になる（ルート線が典型）。解像しないなら沈黙は断定ではない。
3. **係争を解像してしまう場面では、結論でなく証拠を述べる。** どちらが正しいかを言わずに、両説が残した痕跡を両方描く（「名前が ついた 道／紙が 残った 道」）。
4. **きみ（cur）の近傍は描けない。** cur リングとラベル/note のスタックが遮蔽する。近距離の岐路は最小フレーム約392単位（≈380km）を確かめてから企画する。
5. **gaz の合成点は導出を書く。** 2説の算術平均（中点）は、ズームが解像した瞬間に第三の断定になる——両説が合意する地理から取る。
6. **CHAPTER_POINTS に「弾の入った断定」を置かない。** 地図の無いシーンは章既定点にフォールバックする＝既定点は係争に触れない場所を選ぶ。

## 予算表（機械検査 = `tests/style-budget.test.ts`）

計測は純テキスト（タグ・ルビ・空白を除く）。較正元は秀長＝**子どもの実反応で検証済みの唯一のコーパス**の実測＋伸びしろ。

| 指標 | 予算 | 秀長実測（較正値） |
|---|---|---|
| シーン本文 | ≤ 300字 | 平均130字・最長223字 |
| 1シーンの読む量（本文＋内語＋spark＋問い＋信条＋hist） | ≤ 420字 | 292〜420字 |
| 章の本文合計 | ≤ 1000字 | 486〜793字 |
| 本文の括弧注釈 | ≤ 8個/章 | 最多6個 |
| 主線のヘッジ句 | ≤ 2回/章 | 最多1回 |
| deep 1枚 | ≤ 250字 | 最長168字 |
| 人物カード付与 | ≤ 2人/シーン | 最多2人 |
| 人物カード総数 | ≤ 16人/作品 | 10人（清盛16人＝設計目安の上限） |

- **「1シーンの読む量」だけ伸びしろ無し**（理由は `style-budget.test.ts`）。既存の超過章は `LOAD_LEDGER` ＝**新章は登録なし＝最初から予算内**。
- 予算内でも退屈は書ける。機械は床で、天井は `/eval-work` の離脱自由ペルソナと家族プレイの観察メモが判定する。

## 企画フェーズのチェック（章カルテの必須欄）

- 各章の **「本文の代わりに語る装置」** 欄が埋まっているか。過半が「なし／地図（惰性）」なら企画差し戻し＝装置の設計が先。
- 作品の **視覚文法**を選んだか——この人物の力・変化は何に宿るか（土地→地図、位と縁→人の図、金→帳簿・航路）。「秀長で使った装置だから使う」は理由にならない。
