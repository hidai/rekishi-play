# WRITING — 執筆規律（教材コンテンツの書法）

VISION 原則4「人物は声と信条で刻む」・原則5「体感 > 情報」・原則6「わからないことは宝」を、シーン執筆の実務規準に落とした文書。CRITERIA（評価ルーブリック）と対をなす——CRITERIA は「書いた後の判定」、この文書は「書く前・書く最中の設計規準」。

**この文書の規律・下の予算表を「緩める」変更はハード境界（人間のみが行う。AI は改訂案の提案まで）。** 厳しくする・計測を増やす方向の変更は AI が自律で行ってよい。

## 成立の経緯（なぜこの文書があるか）

第2作（清盛）は全7章が `/eval-work` を通過したのに、家族プレイでは「教科書的で、まったく引き込まれない」だった（観察メモ 2026-07-12）。原因は3つ——①評価の非対称②視覚文法のミスマッチ③ヘッジ・メタ視点の主線漏出。この文書と `tests/style-budget.test.ts` は同じ事故を仕組みで防ぐ装置である。計測値・逐語は git と docs/JOURNAL-archive.md。

## 書法（シーン主線の10か条）

1. **1シーン＝1つの絵＋1つの感情＋1つの声。** 2つ目の話題が入りそうになったら、シーンを割るか deep へ出す。
2. **感情は要約しない。** 「おそろしいのは〜だ」「〜という悲しい出来事だった」と地の文で説明しない。声（`.speak`）・monologue・場面の細部（手・目・音）で感じさせる。秀長の実例: 母なかの「そばにいてやっておくれ」の一言が、説明3段落ぶんの仕事をする。
3. **説明は本文に置かない。** 制度・経緯・用語の解説は deep へ。本文の括弧注釈（「安芸＝今の広島…」）は最小限に——注釈が要る語は、そもそも主線に出しすぎのサイン。
4. **主線は熱く、留保は装置で。** 「と伝わる」「とされる」「後の物語は語る」等のヘッジ・史料メタ視点は spark / deep / cite / hist の仕事。主線に混ぜない。創作明示の「——気がした」（G7 様式）はこの制限の対象外。原則6「わからないことは宝」は好奇心の入口の装置であって、主線の温度を下げる免罪符ではない。
5. **人は絞る。** 人物カード付与は1シーン2人まで・1作品16人まで。本文に「名前だけの人物」を出さない——役割語（「院の側近」）で流すか、出すなら声かひっかかりを1つ与える。
6. **本文は短く。** 1シーン300字以内・1章合計1000字以内（純テキスト）。deep は1枚250字以内。迷ったら削る——「思い切って詳細は省く」ことはアンチゴール「網羅しない」が既に許可している。
7. **章の山場は本文以外が語る。** 各章に「本文の代わりに語る装置」（地図・closeup・reveal・ミニゲーム・図）を企画の章カルテで先に決める。装置が「なし」の章は、書く前に装置を用意する。権力・変化の視覚文法は題材に合わせて選ぶ（土地の時代＝地図、位と縁の時代＝人の図・席の図、など）。
8. **選択は分岐で報いる。** どちらを選んでも同じ文面に合流させない。最低でも monologue 一拍か hist の差で「選んだ意味」を返す（VISION 原則1・3の実務）。
9. **小5の音読でリズムを確かめる。** 一文は短く。文語調（「〜ざるを得ない」）・抽象語（「像の下地」）は、小5が音にして意味が届くかで判定する。
10. **パイロットシーン制。** 新作品は全章執筆の前に、代表1シーンを最終レジスタで書いて `/eval-work`（離脱自由ペルソナ）を通し、その register を作品の基準にしてから量産する。

## 地図・図の書法（主ビジュアルの規律）

シーン地図・figure・closeup も執筆物として、この規律で書く（実例・逐語は git と docs/JOURNAL-archive.md）:

1. **開幕にアンカーする。** 地図は本文より先に目に入る establishing shot——読者が最初に立つ場面を表し、まだ読んでいない結末を先に見せない。例外はシーン自体が結末を主題とする場合のみ（むすび・reveal・臨終/滅びの山場）。時間が戻る回想では、時間の手がかり（「〜の 前の 年」等）を本文と地図の両方に置く——塗りだけでは巻き戻しは伝わらない。
2. **地図はヘッジできない——「解像度 vs 係争幅」で判定する。** 地図には「と伝わる」の置き場が無い。マークが係争（諸説の幅）を解像するなら、それは断定になる（進軍・逃走のルート線が典型）。解像しないなら沈黙は断定ではない。
3. **係争を解像してしまう場面では、結論でなく証拠を述べる。** どちらが正しいかを言わずに、両説が残した痕跡を両方描く（「名前が ついた 道／紙が 残った 道」）。
4. **きみ（cur）の近傍は描けない。** cur リングとラベル/note のスタックが遮蔽する（顔は marker の上に浮くので、遮蔽物は顔の円ではない）。近距離の岐路は最小フレーム約392単位（≈380km）を確かめてから企画する。
5. **gaz の合成点は導出を書く。** 2説の算術平均（中点）は、ズームが解像した瞬間に第三の断定になる——両説が合意する地理（共有地盤）から取る。
6. **CHAPTER_POINTS に「弾の入った断定」を置かない。** 地図の無いシーンは裸の cur ピンで章既定点にフォールバックするため、既定点には係争に触れない場所を選ぶ。

## 予算表（機械検査 = `tests/style-budget.test.ts`）

計測はタグ・ルビ（`<rt>`）・空白を除去した純テキスト。較正元は秀長＝**子どもの実反応で「引き込まれる」ことが検証済みの唯一のコーパス**。予算は秀長実測＋伸びしろで、超えたら `npm test`（＝CRITERIA G2）が落ちる。

| 指標 | 予算 | 秀長実測（較正値） |
|---|---|---|
| シーン本文 | ≤ 300字 | 平均130字・最長223字 |
| 章の本文合計 | ≤ 1000字 | 486〜793字 |
| 本文の括弧注釈 | ≤ 8個/章 | 最多6個 |
| 主線のヘッジ句 | ≤ 2回/章 | 最多1回 |
| deep 1枚 | ≤ 250字 | 最長168字 |
| 人物カード付与 | ≤ 2人/シーン | 最多2人 |
| 人物カード総数 | ≤ 16人/作品 | 10人（清盛16人＝設計目安の上限） |

- 清盛の未リライト章は既知の超過として、テスト内の **EXEMPT リスト**に登録済み。体験化リライトで章ごとにリストから外して green にする。**EXEMPT を増やす変更は予算の緩和にあたる**（＝冒頭のハード境界。人間のみ）。
- 予算内でも退屈は書ける。機械検査は下限の防波堤であり、上限の品質は `/eval-work` の離脱自由ペルソナと、最終的には家族プレイの観察メモ（VISION: 最終評価者は子どもたち）が判定する。

## 企画フェーズのチェック（章カルテの必須欄）

- 各章の **「本文の代わりに語る装置」** 欄が埋まっているか。過半の章が「なし／地図（惰性）」なら企画差し戻し＝装置の設計・エンジン拡張が先。
- 作品の **視覚文法**を選んだか——この人物の力・変化は何に宿るか（土地→地図、位と縁→人の図、金と流通→帳簿・航路、など）。「秀長で使った装置だから使う」は理由にならない（観察メモ 2026-07-12 の教訓）。
