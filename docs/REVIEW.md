## ④ 以下は報告（読み飛ばし可）

### 今回書いた章の中身（渋沢 第二章「敵の 家に つかえる」・1864〜1866年）

- 村を捨てて京へ。金は尽き、従兄・長七郎が捕まり、その懐から**自分が書いた手紙**が出て幕府に名を知られる。→ 一橋家の平岡円四郎に呼ばれ「うちへ来い」。→ **選択**（攘夷を貫いてことわる／「ものが言えること」を条件に仕える）→ その夏、平岡が**攘夷派に暗殺される**。→ 与えられた仕事は戦ではなく**兵あつめと商い**（藍を買いつけていたころと同じ顔で村を口説く）。→ 1866年、慶喜が将軍になり、**動いていないのに幕臣になる**。
- **章の装置＝「きみの 座」の図**: 百姓の子 → 攘夷の浪士 → 一橋の家来 → 幕臣 の4つの席を横に並べ、顔は**いまの座にだけ**置きました。上座には将軍。「上の人が動くと、下の座も動く」を絵1枚で言うためです。
- **史実の扱い**: 京へ上った道も仕官のやりとりも、たどれる紙は**本人の後年の回想（『雨夜譚』）1本**しかないことを、そのつど本文の外で名指ししています。事実関係（浪人期間・平岡暗殺・従兄 喜作の戦い）は前回のサイクルで裏取り済みで、**今回のファクトチェックは指摘ゼロ**でした。
