- **★「消してはいけない保留」は登録制**: 「——**と、長く語られてきた**」は検査に引っかかりますが、**同時に「言い伝えであって確定ではない」という大事な保留**です。狙いは「予備知識に寄りかかるな」であって「保留を消せ」ではないので、**残す理由を1行ずつ書いて登録する表**にしました（『家康』5か所＋『清盛』1か所）。
- **★この直しは「引っかかる語を消す」ことではありません**（5サイクルぶん。すべて10歳役が捕捉）: (1) **着せただけでは驚きになりません**（『家康』は規律に完全に合っていたのに「**うん、さっき読んだ**」＝赤枠側に新しい情報が要る）。(2) **語だけ消すと、かえって悪くなります**（『清盛』は裏返す相手ごと「もっと深く」へ潜った＝直すべきは語でなく「**だれが着せたか**」）。(3) **驚きを後ろへ動かすと、答えを先に言う画面が前にできます**（『秀長』＝言い足さず2画面から消した）。(4) **赤枠が、着せたばかりの言葉を復唱すると効果を自分で食います**（『ダビンチ』＝否定から始めたら「最初の一文で『あれ、外れなの!?』となった」）。(5) **着せる画面が保留まで言うと、裏返す画面の仕事が無くなります**（今回『勝海舟』＝保留は文でなく出どころラベルと △ マークへ）。(6) **裏返すために主人公の手柄を足してはいけません**（江戸城を「大勢の手が動いていた」と裏返すつもりが、初版は「**きみが先に使いを送り出していた**」と主人公を有能にした。しかもその使いを出したのは将軍だったという説が主流）。**＝機械の数字が 0 でも「直った」ことにはなりません**ので、毎回 読者役を1本添えています。
