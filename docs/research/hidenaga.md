# リサーチ — 豊臣秀長（第1作 `hidenaga`）

> **位置づけ**: 第1作は旧 vanilla 実装からの移植で始まったため、他4作（kiyomori/katsu/ieyasu/davinci）と違い**リサーチ台帳を持たない**。本文の史実は各章執筆時のファクトチェック（`/eval-work` の G5）で個別に担保してきた。この文書はその欠を全面的に埋めるものではなく、**顔エンジン要件②（通説イメージ忠実性）の監査に必要な §4B だけを先に立てた部分台帳**である。他の節（年表・地理・史料批判）は必要になった回に足す。
> **史料批判の原則**: 秀長は「兄・秀吉を語る史料の中に、脇として現れる」人物で、本人を直接描いた同時代史料が極端に乏しい（＝作品の貫通する謎そのもの）。**顔もまた例外ではなく、本人を写した肖像は存在しない**。

## 0. 確度の凡例

- **◎ 通説** — 複数の信頼できる資料で一致。教材で断定してよい。
- **○ 有力説** — 支持されるが確定ではない。「〜とされる」で書く。
- **△ 諸説あり／不確実** — 断定を避ける。VISION 原則6「わからないことは宝」の入口候補。
- **☆ 伝説・帰属論争** — 史実性・本人性が低い。「伝えられる」と明示して扱う。

## 4B. 風貌・肖像典拠（顔エンジン要件②）

> **位置づけ**: 観察メモ#1 の要件②「有名な歴史的人物は世間のイメージを壊さない絵」の hidenaga 実施（要件① 別人性は `tests/face-distinct.test.ts` の距離フロアが担保する別軸）。設計は [`docs/design/face-engine.md`](../design/face-engine.md) §5＝「research に典拠3層を書いてから faces.ts を見る」。典拠3層＝①肖像・写真の通説 ②大河/銅像/教科書/学習まんがの支配的イメージ ③同時代の風貌記述。**肖像の帰属論争は隠さず教材資源に**（VISION 原則6）。裏取り＝2026-07-23 の web ファクトチェック（sonnet）＋**採用前の反証パス（opus）**。

- **★大友宗麟**: ☆→**補正1件（採用）**。唯一の伝存肖像＝**大徳寺瑞峰院蔵**で、賛の年記は**天正15年(1587)＝本作 第6章と同時代**（宗麟の没年）。そこに描かれるのは**剃髪した僧形**（墨染の衣・朱の袈裟・扇）＋**細い口ひげ**であって、南蛮帽ではない。剃髪は永禄5年(1562)＝**受洗(1578)の16年前**で、九州平定期の宗麟は一貫して僧形。大分市の公共彫像（神宮寺浦公園像・荷揚町の胸像・大分駅前の富永直樹像 1982）も**すべて剃髪**——駅前像はマントと十字架で南蛮色を出すが、それでも帽子はかぶらない。→ faces.ts `head:'nanban'→'bozu'`・`beard:'full'→'mustache'`（灰の細い口ひげ）。**キリシタン性は帽子でなくカード本文と物語が担う**。○ 学び＝「その人の宗教・立場を帽子や小道具で表す」設計は、図像の裏取りを飛ばすと通俗イメージに滑る。
- **明智光秀**: ☆——**補正しない（反証で棄却）**。唯一とされる肖像＝岸和田・本徳寺蔵は無髭で柔和な面貌だが、①賛は慶長18年(1613)＝没後31年で、渡邊大門らが「本人を見て描いたか疑わしい・子の南国梵桂がモデルの可能性」と指摘＝**光秀比定の根拠が弱い** ②江戸〜明治の浮世絵の光秀は**むしろ有髭で猛々しい**（歌川芳虎「名将四天鑑」1864 等・太田記念美術館が「大河の役者像とはだいぶ違う」と明記）＝**単一の通説の顔が存在しない**。→ 現データ（面長・理知の眉・細い眼光・整ったあごひげ＝江戸期系譜の謀反人像）は正当な選択肢として維持。**根拠が拮抗するときは動かさない**。
- **織田信長**: △ 長興寺蔵（狩野元秀筆・1583＝一周忌）が最有名。フロイス『日本史』＝中背・華奢・**ひげが少ない**・声が高い。→ 現データの「口ひげのみ・面長・つり上がった眉・鋭い目」は肖像とフロイス証言の双方に整合。ただし `skin`（青白い）・`iris:'#43304a'`（暗紫）は**典拠のない演出色**＝キャラクター造形の自由域と自覚しておく（他作の tone 用法と同じ扱い・変更不要）。
- **豊臣秀吉**: ◎〜○ 高台寺蔵（狩野光信筆・1599）ほか。「猿」のあだ名・小柄・日焼けは『太閤素生記』や朝鮮側『看羊録』まで広く一致。→ 丸顔・大きな耳・濃い肌・冠は忠実。**「大口の笑い」は肖像に無い性格描写のデフォルメ**（正装の座像は澄ました顔）＝意図的な学習まんが文法ゆえ維持。
- **島津義久**: ◎ 天正15年(1587)の降伏後に**剃髪し法名「龍伯」**＝史実として確定。→ `head:'bozu'` は忠実（カード本文とも一致）。ひげの色は典拠なし＝自由域。
- **千利休**: ○ 長谷川等伯筆「利休居士像」（1595・表家不審菴蔵・重文）＝**黒頭巾**。同時代に「猪首」の記述。→ `head:'zukin'`・こけた頬は忠実。ひげ・閉じた目の細部は図版解説から確証できず自由域（△）。
- **長宗我部元親**: ◎ 秦神社蔵（重文）＝**没後1ヶ月**（1599）に嫡男・盛親が発注＝戦国武将の肖像として信頼度が高い部類。→ 現データ（面長・険しい眉・豊かな髭）と明確に食い違う点は確認できず。細部は図版の直接確認が要る（残タスク・優先度低）。
- **藤堂高虎**: ☆/○ 「六尺二寸（約188cm）の大男」は通説として一致（○）。ただし伝存肖像（伊賀・西蓮寺蔵・寛文11年=1671＝没後41年）は**白髪白髯の老人像**で、現データの黒い豊かな髭とは色が逆。→ **本作の高虎は秀長に仕えた壮年期**（第5〜6章）ゆえ年代が違う＝補正しない。`nose:'tall'`・大柄は通説に忠実。
- **豊臣秀長（主人公）・豊臣秀次・大政所（なか）**: ☆ **そもそも「通説の顔」が確立していない**。春岳院蔵「豊臣秀長画像」は**200回忌(1788頃)に狩野派・梅軒員信が新調した想像画**＝没後約200年で、本人を写した根拠はない。秀次も確立した流布像がなく、大政所も大徳寺伝来像の顔立ちを裏取りできない。→ 現データは物語上の解釈（温厚な補佐役・不安げな後継・やさしい老母）として妥当だが、**「通説準拠」ではなく創作**と自覚しておく。**主人公の顔に確定像が無いこと自体が本作の主題（＝記録に残らなかった人）と響き合う**＝教材ネタ候補。
- **柴田勝家・大友以外の脇役**: △ 勝家の肖像原本は1993年発見・損傷甚大（2006年に修復模写公開）で髪の色を確認できず。賤ヶ岳自刃時 62歳前後＝現データの白髪・老いの皺は史実と整合（変更不要）。

**運用の学び（要件② 4作目・第一作にして最終形）**: (1) **本作は「肖像が無い」型**——davinci＝帰属論争型／katsu＝写真の時代型／kiyomori＝齢・場面型に続く第四の型で、**主人公本人に確定肖像が無い**（想像画すら没後200年）。忠実性監査の焦点が「顔立ちの一致」でなく**「その人がどんな姿でその場にいたか（僧形か・髷か・年代はどこか）」**に移る。(2) **補正シグナルは顔でなく頭に出た**（宗麟の帽子）。head 語彙は身分・宗教・年代を一語で主張するので、典拠の裏取りを飛ばすと最も通俗に滑りやすい。(3) **反証パスが1件を止めた**（光秀）。ファクトチェック単独なら「唯一の肖像は無髭」で補正していたが、その肖像自体の帰属が☆で、かつ江戸期の流布図像は有髭＝**「唯一の肖像」は「通説の顔」と同義ではない**。
