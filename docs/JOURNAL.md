# JOURNAL — 自律開発ジャーナル

セッションをまたいだ引き継ぎ帳。`/auto-dev` の各セッションが末尾に追記する（新しいものが下）。
書くこと: 日付 / やったタスク / 結果（ブランチ・コミット） / 評価の要点 / 次セッションへの申し送り。
**申し送りは AI→AI 専用。** 人間宛のお願い（レビュー観点・実機目視・判断待ち）はここに書き足さず **docs/REVIEW.md へ集約する**（人間は週1バッチ＝細粒度お願いは受け取れない）。
**書く粒度は「大目標に前進したか」で測る。** 脚注1個の純減に長大な正当化を書かない（微粒度スライスは1ブロックに束ねて archive へ）。

**★学び1＝「1語に統一」の副作用は、統一した語が一意になることそのもの**。（3）の学び「制度語は言い換えるより1語に統一して消えることがある」を実行したら、**その語が指すはずのない場所まで新しい意味を吸い込んだ**。実例＝6-b「安徳天皇も、**院**も、しぶしぶ 福原へ」の「院」は元は高倉上皇だが、5章で「院＝後白河ひとり」を叩き込んだ直後なので、**鳥羽殿に幽閉したはずの後白河が引っ越してきた**と読めて筋が切れる（中1と読み通しが独立に major）。統一前の「上皇」は少なくとも「後白河法皇とは別枠の誰か」という信号を持っていた。⇒ **統一は「その語の全出現を数えてから」やる**（同義語を潰すと、残った1語の指示範囲が広がる）。

**★学び2＝言い換えの定義は、同じ画面の反例と突き合わせる**。初版は「院（天皇の 位を ゆずった あとも **力を もつ** 人）」＝〈力〉ベースで定義したが、同じ段落の崇徳院は流罪、5章の後白河院は幽閉される。**定義語と反例が同一トークンになった**（VISION・小5・ファクトチェックが独立に指摘）。しかも小5は逆向きに誤読していた——2-a で会う院が〈死んだ鳥羽〉〈流された崇徳〉の2例だけなので〈院＝負けた人〉の図式ができ、2-b の「いまは 後白河院」を**降格**と読んで「なんで 反乱軍は この人を つかまえるの？」で止まった。直しは定義を〈位置〉へ（「位を **おりた** 人」＝ゆずる／おろされる の両方を覆う）＋ 2-b に力の向きを一句（「天皇の 後ろで 国を 動かす 側だ」）。R2 で小5は「直っている。力のある側に見える」。

**★学び3＝説明の一文を「動作文の途中」に割り込ませると、主語が乗り換わる**。改名の一文を「二人は 手を 組み、兵を あげた。あの 後白河天皇は…いまは 後白河院。御所を 焼き、その 親子を 手の内に」と挿したら、連用中止「焼き」が直前の主題（後白河院）に付いて**被害者が加害者に読める**（中1・VISION が独立に指摘）。史実では焼いたのは信頼・義朝の側。直しは**改名を段落の先頭に独立させる**＋「**院の** 御所」と所有を戻す。⇒ 説明を差す位置は、その段落の**主語の連鎖**を壊さない所に限る（（8）の「挿す位置が隣の文の主語を書き換える」の再発・同型2例目）。
