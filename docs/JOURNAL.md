# JOURNAL — 自律開発ジャーナル

セッションをまたいだ引き継ぎ帳。`/auto-dev` の各セッションが末尾に追記する（新しいものが下）。
書くこと: 日付 / やったタスク / 結果（ブランチ・コミット） / 評価の要点 / 次セッションへの申し送り。
**申し送りは AI→AI 専用。** 人間宛のお願い（レビュー観点・実機目視・判断待ち）はここに書き足さず **docs/REVIEW.md へ集約する**（人間は週1バッチ＝細粒度お願いは受け取れない）。
**書く粒度は「大目標に前進したか」で測る。** 脚注1個の純減に長大な正当化を書かない（微粒度スライスは1ブロックに束ねて archive へ）。

## 2026-08-05（8） 型10「きみに宛てられた声」を7作49章で数えた（直す前に数える）

**タスク**: 前サイクルが起票した型10。`agency-audit` は声の数と向きのある行為を見るが**声の宛先を
見ていない**（「家中が割れた」画面は声2で ○）。BACKLOG の指示どおり**この回は1画面も直さず、
計器に宛先の列を足して実測だけ**した。設計・全表・限界は [engagement.md](design/engagement.md) **§19**。

**★学び1＝丁寧語は宛先ではない。** 判定を「聞き手がいる声」にすると ます形（「ふえまするぞ」）が
全部通り、**観察の起点だった ieyasu 6-b が満点になる**——子どもが「だれも話しかけてこない」と
読んだ画面が、だ。対者敬語は聞き手の**存在**しか示さない。数えるのは**要求・呼びかけ・問い**
（＝返事を待つ声）だけ。判定は形と錨（隣の地の文が「きみ」を名ざす）の AND で、片方だけだと
遠くの誰かへの命令／きみの前の会話をそれぞれ拾う。

**★学び2＝型9 の上位2作が、型10 の下位2作だった。** 家康 19%・渋沢 27% ⇄ 秀長 60%・政子 50%。
**いちばん台詞が多い作品（26声・30声）が、いちばんきみに話しかけない**——声が「きみの前で
交わされる会議」に使われている。較正元の秀長は型9 では中位で型10 で上位＝**子どもが読めた
コーパスの説明は、声の多さでなく宛先の向き**。ゆえに型9 の score には足さない（別の軸）。

**★学び3＝`class="speak"` は「他人の声」ではなかった**（自己レビューが実データで摘出・型9 の回と
同じく **eval の軸は全部通っていた**）。渋沢 6-b の**きみ自身が頼む台詞**を「宛てられた声」として
数えていた。日本語では**話者の印が声の外**にあり、前にも後ろにも置かれる。⚠️ 錨を目的格
（きみを・きみに）へ絞る修正は**実データの半分**（「母うえ。」等の正しい呼びかけ）を落とした＝
**主語省略のある言語では、格で話者は決まらない**。採った形＝①名で呼ぶ声・二人称の声は**きみ自身の
声ではありえない**ので無条件に数える ②要求・問いだけの声は帰属が無く直前がきみ主語のとき落とす。
同じレビューで「猿の 弟、**か**。」（詠嘆）と「落ちる **もの**。」（名詞化）の誤検出も出た。
⚠️ 「もの」を外して初めて、清盛 3-c が**誤爆だけで正解になっていた**ことが見えた（§18-5 の再演）。

**★学び4＝作品固有の名は、計器に二度書かない。** 呼びかけ（「小竹や。」「父上。」）には主人公の
呼び名が要るが、型4 の `RENAMED_NAMES` ＋ `shortNames` から引けば新しい表は不要（`callNames`）。
⚠️ 逆に見つけた**様式の不揃い**: 終章の謎の再掲を `class="speak"` で書く作品と書かない作品がある
（渋沢だけ speak 無し）＝章7 の値は作中人物の声ではない分を含む。

**評価**: コード差分のみ（作品データ無変更）＝ G1/G2 で足りる。check 0 errors・1305 tests 緑
（較正テスト8本追加：3-a2＝2/2・ieyasu 6-b＝1/3・6-b2＝0・ます形 0・shibusawa 6-b＝0・
hidenaga 2-c＝0・kiyomori 3-c＝1）。
